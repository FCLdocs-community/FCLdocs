# 什么是 Java？

**[Java](window:/term/Java)** 是一门**编程语言**，由 Sun 公司（后被 Oracle 收购）在 1995 年发布，是全球使用最广泛的编程语言之一。它广泛用于企业级后端开发、Android 应用，以及 **Minecraft Java 版**。

Minecraft 之所以是"Java 版"，正是因为它是用 Java 这门语言写成的。

## Java 的主要特点

**1. 面向对象**

Java 把程序组织成一个个"对象"，每个对象有自己的数据与行为。例如"汽车"对象有颜色、速度（数据），能加速、刹车（行为）。这种组织方式接近人的思维，适合编写大型程序。

**2. 跨平台（最关键）**

Java 最核心的卖点是 **"Write Once, Run Anywhere"（一次编写，到处运行）**。C/C++ 程序在某个平台编译后只能在该平台运行；Java 则不同——一份代码编译成**[字节码](window:/term/字节码)**后，只要目标平台装有 [JRE](window:/term/JRE)（Java 运行环境），就能在 Windows、macOS、Linux 上运行。Minecraft 的跨平台特性即源于此。

**3. 自动[内存](window:/term/内存)管理（GC）**

C++ 程序员需要手动分配和释放内存，容易造成[内存泄漏](window:/term/内存泄漏)。Java 提供 **[垃圾回收（GC）](window:/term/GC)** 自动回收不再使用的对象，降低出错率。

**4. 生态成熟**

Java 拥有海量开源库（jar 包），需要什么功能基本都能找到现成实现。

## JVM 是什么？为什么能跨平台？

**[JVM](window:/term/JVM)**（Java Virtual Machine，Java 虚拟机）是 Java 跨平台的关键。它的作用是把 Java 的字节码"翻译"为当前平台能执行的[机器码](window:/term/机器码)。

编译与运行流程：

```
Java 源代码 (.java)
       ↓ 用 javac 编译
Java 字节码 (.class / .jar)
       ↓ JVM 解释执行（或 JIT 编译）
机器码（在 CPU 上运行）
```

- `.java`：源代码，由人编写；
- `.class`：编译后的**字节码**，不是机器码，是 JVM 能解释的中间格式；
- `.jar`：Java Archive，将多个 `.class` 打包成一个文件，便于分发；
- **JVM**：将字节码翻译并执行。每个平台有各自的 JVM（Windows 版、macOS 版、Linux 版），但它们都能运行同一份字节码。

:::note 名词解释
**字节码（Bytecode）**：Java 源代码编译后的中间格式，需要 JVM 翻译为机器码才能运行。
:::

## Java 的版本

Java 版本号较多，与 Minecraft 相关的版本如下：

| [JDK](window:/term/JDK) | 发布时间 | 说明 | 对应 Minecraft 版本 |
|---|---|---|---|
| JDK 8 | 2014 | 最经典、使用最广 | 1.16.5 及更早 |
| JDK 11 | 2018 | 长期支持版（LTS） | —— |
| JDK 17 | 2021 | LTS | 1.18 ~ 1.20.4 |
| JDK 21 | 2023 | LTS | 1.20.5 ~ 1.21.x |
| JDK 25 | 2025 | 当前最新 LTS | 26.1 及以后 |

:::note JDK 与 JRE
**JDK**（Java Development Kit）是开发工具包，包含 JVM、编译器与标准库；**JRE**（Java Runtime Environment）只含 JVM 与标准库，仅运行 Java 程序则安装 JRE 即可。自 JDK 11 起 Oracle 不再单独提供 JRE，故现在通常直接安装 JDK。
:::

## 为什么 Minecraft 使用 Java？

Minecraft Java 版由 Notch（Markus Persson）于 2009 年使用 Java 开发，原因包括：

1. **跨平台**：Notch 希望 Windows、macOS、Linux 玩家都能游玩；
2. **开发效率**：Java 生态完善，便于快速迭代；
3. **个人偏好**：Notch 熟悉 Java。

Java 也有其固有代价：

- **启动慢**：JVM 需要初始化；
- **占内存**：JVM 自身需数百 MB；
- **GC 卡顿**：垃圾回收可能造成短暂停顿。

因此 Minecraft Java 版通常表现为吃内存、启动慢、偶发卡顿。基岩版用 C++ 编写，无此类问题，但 Java 版**[模组](window:/term/mod)生态丰富**，仍是多数玩家的选择。

## Java 与 JavaScript 是一回事吗？

**不是。** 两者除了名字相似，语法、用途与运行环境都不同：

- **Java**：Sun/Oracle 的编程语言，用于后端、Android、Minecraft；
- **JavaScript（JS）**：网景公司的脚本语言，用于网页交互。

两者名字相近，是因为 1995 年网景公司将 LiveScript 改名以蹭 Java 的热度，但二者没有关系。
