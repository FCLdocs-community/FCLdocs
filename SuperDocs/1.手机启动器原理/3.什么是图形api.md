# 什么是图形 API？

## 图形 API 是什么

**图形 API**（Graphics API）是程序与显卡（[GPU](window:/term/GPU)）之间的一套**标准化命令接口**。程序通过它向 GPU 提交绘图指令，而无需关心 GPU 的具体型号与厂商。

:::note 名词解释
**API**（Application Programming Interface）：应用程序编程接口，即"程序之间对话的标准"。图形 API 就是"程序和 GPU 对话的标准"。
:::

没有图形 API 时，每个程序都要分别适配 NVIDIA、AMD、Intel 等各家显卡的细节；有了图形 API，程序只需按统一标准调用，"一次编写，所有 GPU 都能运行"。

## 主流图形 API

| 图形 API | 开发方 | 平台 | 特点 |
|---|---|---|---|
| **OpenGL** | SGI → Khronos | 跨平台（PC、手机、嵌入式） | 老牌、跨平台、功能已冻结 |
| **Vulkan** | Khronos | 跨平台（PC、手机） | 现代、性能强、学习成本高 |
| **DirectX（Direct3D）** | 微软 | Windows、Xbox | Windows 专用、性能强 |
| **Metal** | 苹果 | iOS、macOS | 苹果专用、性能强 |
| **OpenGL ES** | Khronos | 手机、嵌入式 | OpenGL 的移动版 |

## OpenGL

**OpenGL**（Open Graphics Library）由 SGI 于 1992 年发布，现由 **Khronos Group** 维护，是最老牌、最通用的图形 API。

- **跨平台**：Windows、macOS、Linux、手机（通过 [OpenGL ES](window:/term/OpenGLES)）均可用；
- **状态机模型**：设置好状态（颜色、纹理等）后保持，直到再次修改；
- **使用简单**：设计直观，适合入门；
- **功能已冻结**：[Khronos](window:/term/KhronosGroup) 已停止为其添加新功能，转向主推 [Vulkan](window:/term/Vulkan)，但 [OpenGL](window:/term/OpenGL) 4.6 仍足够使用。

:::note 名词解释
**Khronos Group**：由 Apple、Intel、NVIDIA、AMD、Google 等组成的开放标准联盟，维护 OpenGL、Vulkan、OpenCL 等标准。
:::

Minecraft [Java](window:/term/Java) 版使用 OpenGL（经 [LWJGL](window:/term/LWJGL) 调用），这也是它跨平台的原因。

## Vulkan

**Vulkan** 由 Khronos 于 2016 年发布，是 OpenGL 的继任者。

- **跨平台**：Windows、Linux、Android 均可用（macOS 经 **MoltenVK** 转换到 Metal）；
- **性能强**：相比 OpenGL 可显著降低 [CPU](window:/term/CPU) 开销，从而提升[帧率](window:/term/帧率)；
- **多线程友好**：可利用多核 CPU 并行提交渲染命令；
- **显式控制**：[内存](window:/term/内存)、同步、管线均需程序自行管理，功能强大但学习成本高。

Vulkan 广泛用于追求性能的 AAA 游戏与游戏引擎。

:::note 名词解释
- **AAA 游戏**：投入大、画面好、规模大的顶级游戏（如 GTA、赛博朋克）；
- **引擎**：一套现成的游戏开发工具。
:::

从 **Minecraft 26.2** 开始，游戏提供了针对 Vulkan 的渲染适配（**Vulkan 渲染后端**，实验性），可在图形设置中在"默认 / 优先使用 Vulkan（实验性）/ 优先使用 OpenGL"之间切换。需要设备支持 Vulkan 1.2 及以上，不满足时回退到 OpenGL。

:::tip
目前只有部分移动端 SoC（以骁龙为主）内置的 GPU 可运行 Minecraft 的 Vulkan 模式，其余或因 Vulkan 版本不够新，或因移动端设计差异，无法满足要求。
:::

## DirectX（Direct3D）

**DirectX** 是微软 1995 年推出的多媒体 API 集合，其中负责 3D 图形的部分称 **Direct3D**（D3D）。

- **Windows 专用**：只能在 Windows、Xbox 上使用；
- **性能强**：与 Vulkan 同级；
- **生态成熟**：Windows 游戏基本都基于它；
- **版本**：[DirectX](window:/term/DirectX) 9/10/11/12，其中 **DirectX 12**（2015）是类似 Vulkan 的底层 API。

DirectX 无法在手机、macOS、Linux 上直接运行（除非经 [Wine](window:/term/Wine) + [DXVK](window:/term/DXVK) 等转换层）。

:::note 名词解释
- **Wine**：让 Linux/macOS 运行 Windows 程序的兼容工具；
- **DXVK**：Wine 中把 DirectX 绘图指令转换为 Vulkan 的组件。
:::

## Metal

**Metal** 是苹果 2014 年推出的图形 API，仅用于苹果设备（iPhone、iPad、Mac）。

- **苹果专用**：iOS、macOS 均使用；
- **性能强**：与 Vulkan、DirectX 12 同级；
- **取代 OpenGL**：苹果已停止更新 OpenGL，主推 [Metal](window:/term/Metal)。

iPhone 上的游戏、Minecraft 基岩版 iOS 版均使用 Metal。

## OpenGL ES

**OpenGL ES**（Embedded Systems）是 OpenGL 的移动版，专为手机与嵌入式设备设计。

- **简化版**：移除部分复杂功能，适合资源受限设备；
- **跨平台**：Android、iOS（被 Metal 取代前）、嵌入式设备均可用；
- **版本**：1.0（固定管线）、2.0（可编程管线）、3.0、3.2。固定管线下画图步骤固定，只能调参数；可编程管线允许自行编写着色器，更灵活；
- **主流**：Android 手机普遍支持 OpenGL ES 3.2。

## 各 API 对比

| API | 平台 | 性能 | 难度 | 状态 |
|---|---|---|---|---|
| OpenGL | 跨平台 | 中 | 易 | 维护中（不更新） |
| OpenGL ES | 移动 | 中 | 易 | 维护中 |
| Vulkan | 跨平台 | 高 | 难 | 活跃 |
| DirectX 12 | Windows | 高 | 难 | 活跃 |
| Metal | 苹果 | 高 | 中 | 活跃 |

## 图形 API 与 Minecraft 的关系

- **Minecraft Java 版**：使用 OpenGL，26.2 起可选用实验性的 Vulkan 后端；
- **Minecraft 基岩版**：使用 DirectX（Windows）、Metal（iOS/macOS）、OpenGL ES / Vulkan（Android）；
- **手机运行 Java 版**（ZalithLauncher、Fold Craft Launcher 等）：将 OpenGL 调用转换为 OpenGL ES / Vulkan（经 [GL4ES](window:/term/GL4ES)、[ANGLE](window:/term/ANGLE)、[Zink](window:/term/Zink) 等[渲染器](window:/term/渲染器)）。
