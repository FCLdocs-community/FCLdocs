# 什么是图形渲染器？

:::note 术语说明
在 Minecraft 手机启动器领域，"渲染器"通常特指 **OpenGL 的实现方式**，即解决图形 API 差异的工具（详见[渲染器](/SuperDocs/手机启动器原理/渲染器)）。本节讨论的是更一般的"渲染器"概念，不要混淆。
:::

## 渲染器是什么

**[渲染器](window:/term/渲染器)**（Renderer）是负责把 3D 场景数据转换为 2D 画面像素的程序。它接收场景（模型、材质、光照、相机），输出最终显示在屏幕上的图像。

具体到 Minecraft：

- **场景数据**：方块、生物、玩家位置、光照、视角；
- **渲染器**：将这些数据绘制为画面；
- **输出**：屏幕上看到的方块世界。

## 渲染器 = 图形 API + 自定义 GLSL

一个完整的渲染器由两部分组成：

1. **图形 API**：与 [GPU](window:/term/GPU) 对话的底层接口（OpenGL、Vulkan 等）；
2. **自定义 GLSL**：实现具体画图逻辑的着色器代码。

仅有图形 API 不够——API 只能绘制三角形、设置颜色，无法直接画出 Minecraft 的方块风格与[光影](window:/term/光影)效果。要写出 GLSL 着色器，告诉 GPU"这个方块怎么画、光怎么打、阴影怎么算"，才能渲染出 Minecraft 的画面。

## 什么是 GLSL

**GLSL**（OpenGL Shading Language，OpenGL 着色语言）是 OpenGL 使用的编程语言，专门写给 GPU 执行。

:::note 名词解释
**着色器（Shader）**：一段给 GPU 执行的小程序，决定每个像素、每个顶点如何绘制。用 GLSL（OpenGL）、HLSL（DirectX）、MSL（Metal）等语言编写。
:::

### 着色器类型

| 类型 | 作用 |
|---|---|
| **顶点着色器** | 处理顶点（3D 模型的角点），决定每个点画在屏幕哪里 |
| **片段着色器** | 处理像素，决定每个点最终是什么颜色 |
| 几何着色器 | 可选阶段，可生成新的图元，用于粒子、阴影体等高级效果 |
| 曲面细分 / 计算着色器 | 现代 API 中的高级阶段，用于曲面细分与通用计算 |

Minecraft 原版及大多数光影包主要使用顶点着色器和片段着色器。

例如绘制一个方块：顶点着色器决定方块的 8 个角点在屏幕的位置，片段着色器决定每个表面像素是泥土色、草色还是石头色。

## Minecraft 的渲染器为何不断演进与替换

Minecraft 语境的"换渲染器"包含**官方演进**与**社区替换**两个层面。

### 官方层面（Mojang 的底层重构）

Mojang 一直在迭代 [Java](window:/term/Java) 版渲染引擎。1.17 引入全新的底层渲染引擎 **Blaze3D**，重写了大量渲染逻辑。出于跨平台兼容性的考虑，Mojang 长期坚守 OpenGL，官方内置的 GLSL 着色器以保证游戏正常运行为目标，画面相对朴素。从 26.2 起，Mojang 开始引入 **Vulkan 渲染后端**（实验性），以提升渲染性能，长期仅依赖 OpenGL 的局面开始改变。

### 社区层面（Mod 开发者的替换）

社区玩家对**性能**与**画质**的追求催生了替换官方渲染逻辑的第三方方案，分为两个方向：

- **为了画质（替换 GLSL 着色器）**：光影包（如 [BSL](https://bitslablab.com/bslshaders/)、[Continuum](https://continuum.graphics/)）本质上是一套用 GLSL 编写的自定义着色器集合，替换原版的简单着色器以获得真实光影。为加载它们，社区开发了 [OptiFine](https://optifine.net/)、[Iris](https://irisshaders.dev/) 等光影加载器。
- **为了性能（替换渲染逻辑或图形 API）**：[Sodium](https://github.com/CaffeineMC/sodium) 用现代 OpenGL 重写渲染逻辑以提升[帧率](window:/term/帧率)；[VulkanMod](https://github.com/xCollateral/VulkanMod) 将图形 API 从 OpenGL 替换为 Vulkan 以降低 [CPU](window:/term/CPU) 开销。

## Minecraft 主流渲染器 / 优化 Mod

| 方案 | 图形 API | GLSL | 说明 |
|---|---|---|---|
| 原版渲染器 | OpenGL | Mojang 内置 | 性能一般，画面朴素 |
| [OptiFine](window:/term/OptiFine) | OpenGL | 自写着色器 | 优化 + 光影，更新慢、与部分 [Mod](window:/term/mod) 不兼容 |
| [Iris](window:/term/Iris) Shaders | OpenGL | 自写着色器 | 与 [Sodium](window:/term/Sodium) 兼容的新一代光影方案 |
| Sodium | OpenGL | 优化渲染逻辑 | 大幅提升帧率，只优化不加光影 |
| VulkanMod | Vulkan | SPIR-V | 降低 CPU 开销，兼容性有限，实验性 |
| Canvas | OpenGL | 自定义着色器 | 新渲染框架，与 Sodium 配合 |

:::note 名词解释
**SPIR-V**：Vulkan 的着色器文件格式，类似 GLSL 但专用于 Vulkan。
:::

## 手机上运行渲染器的差异

手机运行 Minecraft Java 版时，渲染器需要额外适配：

- **图形 API**：OpenGL → 转换为 OpenGL ES / Vulkan（经 GL4ES / Zink / ANGLE 等）；
- **GLSL**：GLSL → 转换为 GLSL ES 或 SPIR-V。

因此手机上运行光影的损耗高于电脑，但中高端手机仍可运行基础光影。具体的转换过程与限制见[着色器](/SuperDocs/手机启动器原理/着色器)。

:::note 关于 Minecraft 基岩版
基岩版使用完全不同的 **RenderDragon** 渲染引擎，原生支持 Vulkan、DirectX 12 等现代图形 API，并内置光线追踪功能，但其光影生态与 Java 版不通用。

**光线追踪**：模拟真实光线的反射、折射与阴影，使水面、玻璃、镜子等更具真实感。
:::
