# 后端（pojav-boat）

在手机 Minecraft [Java](window:/term/Java) 版领域，**后端（Backend）** 指启动器中负责真正运行游戏的那套底层：[JVM](window:/term/JVM) 启动、图形桥接、输入桥接、渲染对接。启动器界面可以千差万别，但底层只有两条主要路线：**Pojav 系**与 **Boat 系**。本节介绍两者的起源、架构与差异，以及 FCL 所处的位置。

## 技术谱系

```
Boardwalk（2014，zhuowei）   ← 最早将 JVM 移植到 Android 的尝试
      │
      ├──→ PojavLauncher（2020，PojavLauncherTeam）
      │         │  （已停止维护并归档）
      │         ├──→ Amethyst-Android（AngelAuraMC，官方续作）
      │         │         │
      │         │         ├──→ Fold Craft Launcher（FCL-Team）
      │         │         ├──→ ZalithLauncher 1 / 2
      │         │         └──→ 其他 Pojav 系启动器
      │         │
      │         └──→ PojavLauncher_iOS（iOS 分支）
      │
      └──→ Boat（2020，AOF-Dev）
                │
                ├──→ MCinaBox（AOF-Dev，首个基于 Boat 的启动器）
                └──→ 澪启动器（Mio，"Boat澪"）等 Boat 系启动器
```

:::note 同名"Mio Launcher"的区分
GitHub 上有两个"Mio Launcher"：
- [SkyWings23/MioLauncher](https://github.com/SkyWings23/MioLauncher)：**Pojav 系**，源码含 `net.kdt.pojavlaunch` 包；
- 国服常说的"澪启动器（Boat澪）"：基于 **Boat** 的另一个项目，0.4 版本源码以存档形式公开于 [root-S7/Mio-Ultimate](https://github.com/root-S7/Mio-Ultimate)。

两者同名不同源，查阅资料时注意区分。
:::

## Pojav 系：单进程方案

Pojav 系的核心特征是**游戏运行在启动器自己的进程内**。以 FCL 源码（`FCLauncher.java`）为例，完整链路为：

```
启动器 App 进程
├── 1. dlopen JVM 依赖库（libjvm.so 等）          ← Java 移植篇
├── 2. 写入环境变量（POJAV_RENDERER、LD_LIBRARY_PATH 等）
├── 3. dlopen 渲染器 GL/EGL 库                    ← 渲染器篇
├── 4. VMLauncher.launchJVM(args)                 ← 进程内启动 JVM
└── 5. JVM 运行 Minecraft，画面绘制到 Surface，输入经事件管道回流
```

**优点**

- 结构简单、启动快、资源占用小；
- 启动器可直接获取游戏状态（[FPS](window:/term/帧率)、退出码、[日志](window:/term/日志)），功能联动方便；
- 生态庞大：FCL、ZalithLauncher、Amethyst 共享同一套底层，[渲染器](window:/term/渲染器)/[驱动](window:/term/驱动)[插件](window:/term/插件)可互通（FCL 的渲染器插件 v2 格式与 ZalithLauncher 对齐）。

**缺点**

- 游戏[崩溃](window:/term/崩溃)会连带启动器进程一起退出，界面随之消失；
- JVM 与 Android 运行时共处一个进程，个别 so 符号冲突需借助 hook 规避（FCL 的 `jvm_hooks`、`native_hooks` 即为此设计）。

FCL 在这条路线上做了大量增强：使用 **fclcore**（HMCL 核心的移植，管理版本、[下载](window:/term/下载)、[整合包](window:/term/整合包)）、自研 **com.mio** 代码层（插件系统、渲染器管理），并实现了渲染器/驱动/原生库的插件化。准确描述为：**Amethyst 后端 + HMCL 核心 + 自研插件体系**。

### FCL 曾经同时支持 Pojav 与 Boat

FCL 并非从一开始就只用 Pojav 后端。**1.2.9.2 及以前**，启动器同时内置了 Pojav 与 Boat 两套后端，启动界面可以在两者之间切换：源码里有 `launch_pojav` / `launch_boat` 两个选项，运行[目录](window:/term/文件夹)里也带着 `lwjgl-boat` 资产。也就是说，当时的 FCL 既能走 Pojav 的进程内方案，也能走 Boat 的独立进程方案。

到 **1.2.9.3**（2026 年 3 月），为了升级底层 LWJGL，FCL 在 PR #1451（`Feat/lwjgl3.3.6`）中删除了 Boat 后端与 `LWJGL-Boat` 模块，只保留 Pojav 路线。官方还另外发布了一个 **`boat` 版本**：发布说明写明它是「最后一个带 Boat 后端的版本」，[APK](window:/term/安装包) 名为 `FCL-release-1.2.9.2-last-version-with-boat-*`，可与已安装版本共存，供仍需要 Boat 的用户使用。

因此，现在的 FCL 属于 Pojav 系；Boat 只是它早期提供过的另一种选择。

## Boat 系：独立进程方案

[Boat](https://github.com/AOF-Dev/Boat) 的定位是"**不是启动器**，而是一个在 Android 上运行图形程序的环境库（以 aar 发布）"，由 AOF-Dev 于 2020 年创建，前身是 zhuowei 的 Boardwalk。其架构与 Pojav 系不同：

```
启动器 App（管理界面）
    │ 拉起
BoatActivity（TextureView + ANativeWindow）
    │ 将 Surface 与事件管道交给 ↓
游戏进程（由脚本启动的独立 Linux 进程）
├── JVM 在此运行
├── 渲染直连 ANativeWindow（或经 VirGL）
└── 输入经管道进入（pushEventKey / pushEventPointer）
```

从源码（`boat/src/main/java/cosine/boat/`）可见几个设计点：

- **`BoatTask` 按脚本启动游戏**：JVM、库[路径](window:/term/路径)、环境变量写入一个 shell 脚本，由 Boat 执行，灵活性高，理论上可运行不止 Minecraft；
- **事件管道**：`BoatLib.pushEventKey/Pointer/Window` 将 Android 侧输入写入管道，游戏侧的 glfw-boat 读取；
- **`VirglService`**：内置 virgl 渲染服务支持；
- 早期配套 [xserver-xboat](https://github.com/AOF-Dev/xserver-xboat)（由 Xephyr 移植的 X server）。

**优点**

- **进程隔离**：游戏崩溃不影响启动器界面，日志与恢复更友好；
- 运行环境更接近纯 Linux，兼容一些老程序。

**缺点**

- 多一层进程间通信，输入延迟与帧同步的实现更复杂；
- Boat 不是启动器本体，功能需上层自行实现，生态与迭代速度弱于 Pojav 系；
- 项目 2021 年后基本停更，社区维护力量薄弱。

### 代表启动器

- **MCinaBox**（[AOF-Dev/MCinaBox](https://github.com/AOF-Dev/MCinaBox)）：2020 年发布的首个 Boat 系启动器，曾是国内 Java 手机玩家的主要选择，现已停更；
- **澪启动器（Mio，"Boat澪"）**：基于 Boat 的国产启动器，是 Boat 路线后期的代表之一。其 0.4 版本在 Android 13+ 上暴露出的 Java 运行时问题，也侧面反映了 Boat 系维护乏力的现状。
- **FCL（1.2.9.2 及以前）**：曾同时提供 Pojav 与 Boat 两种后端，1.2.9.3 起移除 Boat，只保留 Pojav 路线（详见上文）。

## 两条路线的对比

| 维度 | Pojav 系（FCL 属此） | Boat 系 |
|---|---|---|
| 游戏进程 | 启动器进程内 | 独立进程 |
| 渲染对接 | egl_bridge + 渲染器库 | ANativeWindow 直连 / VirGL |
| 输入 | 事件管道（GLFW 语义） | 事件管道（自定语义） |
| 生态 | 丰富，插件互通（FCL/ZL/Amethyst） | 小众，趋于沉寂 |
| 代表 | FCL、ZalithLauncher、Amethyst | MCinaBox、澪启动器 |

对于普通玩家，日常游玩选择 Pojav 系（如 FCL）即可：版本支持全、更新勤、插件多；Boat 系如今更偏向技术研究。
