# 全局游戏设置

全局游戏设置位于 **设置 → 全局游戏设置**，它决定当前档案下、所有使用全局设置的版本如何启动游戏。

:::note 适用范围
- 在具体版本的「版本设置」中单独修改过的项目，会覆盖这里的全局值；只有未单独设置的项目才使用全局值。
- 该页与「版本设置」页共用同一套界面与数据结构，区别只是作用对象不同。
:::

## Java 版本

选择启动游戏所使用的 [Java](window:/term/Java) 运行时，默认为 **自动选择**。

- **自动选择**：根据游戏版本要求的 Java 主版本，在已安装的运行时中寻找**完全匹配**的版本；没有完全匹配时，选用**版本号最小且高于要求**的运行时。
- **手动选择**：点右侧编辑按钮打开 Java 管理对话框，可查看已导入的运行时、删除某个运行时，或点「导入」添加自行[下载](window:/term/下载)的 `.tar.xz` 运行时包。
- 右侧「安装」按钮会打开 FCL 官方提供的 Java 运行时下载页（GitHub / 网盘）。
- 同一对话框内还提供「执行 Jar 文件」，用于运行可执行 Jar（进阶功能），与启动游戏无关。

## 版本隔离

控制游戏文件（`mods`、`saves`、`config` 等）是否存放在该版本的独立[目录](window:/term/文件夹)中。

| 状态 | 游戏目录 | 效果 |
|---|---|---|
| 开启（默认） | `versions/<版本名>` | 各版本的[模组](window:/term/mod)、[存档](window:/term/存档)、配置互不影响 |
| 关闭 | 共享的 `.minecraft` 目录 | 所有未隔离的版本共用同一套游戏文件 |

[整合包](window:/term/整合包)版本固定使用独立目录，无法关闭。

## 游戏内存

设置游戏可用的最大[内存](window:/term/内存)，进度条范围为 0 到设备总内存。

- **自动分配内存**（默认开启）：滑块值作为**最低分配**，实际分配由启动器按设备空闲内存计算：
  - 先为空闲内存预留 384 MiB；
  - 空闲内存不超过 8 GiB 时，建议值为空闲内存的 80%；
  - 超过 8 GiB 时，建议值为 8 GiB × 80% 加上超出部分的 20%；
  - 结果上限为 16 GiB，且不低于滑块设定值。
- **手动分配**：直接使用滑块设定的数值。
- 界面会显示「设备中已使用 / 设备总内存」，并在设定值超过当前可用内存时给出提示。

:::warning
分配值接近或超过设备可用内存时，系统可能杀掉后台进程，导致游戏闪退或设备卡顿。通常建议给系统保留 2 GB 以上内存。
:::

## 服务器地址

填写[服务器](window:/term/服务器)地址（`IP` 或 `IP:端口`），启动游戏后自动加入该服务器。启动器会根据游戏版本选择不同的进服参数：

| 游戏版本 | 实际传入参数 |
|---|---|
| 低于 1.20 | `--server <地址> --port <端口>` |
| 1.20 及以上 | `--quickPlayMultiplayer <地址:端口>` |

[端口](window:/term/端口)未填写时按 `25565` 处理。地址非法时该参数会被忽略，游戏正常启动但不自动进服。

## 控制

选择该版本使用的**控制布局**（屏幕虚拟按键方案），默认为 `Default`。

- 右侧编辑按钮打开布局选择对话框，从已安装的布局中选择；
- 右侧「安装」按钮跳转到启动器内的「控制」页面，用于新建或导入布局；
- 布局的具体编辑方式见「控制」相关章节。

## 图形后端

选择 Minecraft 使用的图形渲染后端，可选值：

| 选项 | 含义 |
|---|---|
| `default` | 由游戏自行决定 |
| `opengl` | 优先使用 OpenGL |
| `vulkan` | 优先使用 Vulkan |

该选项**仅对 Minecraft 26.2 及以上版本生效**（26.2 起游戏才提供 Vulkan 渲染后端），旧版本设置无效。

## OpenGL 实现方式（渲染器）

选择把游戏的 OpenGL 调用转换为手机 [GPU](window:/term/GPU) 指令的实现，默认为 **Krypton Wrapper（NG-GL4ES）**。可用[渲染器](window:/term/渲染器)如下：

| 渲染器 | 兼容上限 | 说明 |
|---|---|---|
| Krypton Wrapper（NG-GL4ES） | 26.2 | 默认，均衡 |
| Holy-GL4ES | 1.21.4 | 经典 GL4ES 系，老版本稳定 |
| VGPU | 1.16.5 | 轻量方案，远古版本 |
| Zink | 26.2 | Mesa 的 OpenGL→Vulkan 实现 |
| MobileGlues | 无上限 | 专为 MC 设计，适合新版本与[光影](window:/term/光影) |
| [插件](window:/term/插件)渲染器 | 由插件声明 | VirGL、Freedreno 等 |

对话框右上角还有三个入口：

- **齿轮**：配置当前内置渲染器的可调环境变量（如 MobileGlues 的运行时参数）；
- **刷新**：重新扫描渲染器插件；
- **高级**：配置 SFPEW 兼容层（仅对外部渲染器插件生效）与 relaxed context 选项。

右侧「安装」按钮打开渲染器插件下载页。各渲染器的详细差异见[渲染器](/SuperDocs/手机启动器原理/渲染器)。

## Vulkan 驱动

这组设置决定走 Vulkan 时使用哪套[驱动](window:/term/驱动)。

- **使用系统 Vulkan 驱动**（默认关闭）：
  - 关闭时，使用下方「Vulkan 驱动」中选定的驱动（内置 **Turnip**，或已安装的驱动插件）；
  - 开启时，改用系统自带 Vulkan 驱动，兼容性更好但性能表现取决于设备厂商；开启后「Vulkan 驱动」一行会隐藏。
- **Vulkan 驱动**：驱动列表由内置 Turnip 与已安装的驱动插件组成。选择后，启动器会使用对应驱动启动游戏。驱动插件的加载机制见[渲染器](/SuperDocs/手机启动器原理/渲染器)。

## Vulkan 兼容性检测

- **检测 Vulkan**：执行一次 Vulkan 能力检测，对话框中显示 Vulkan 版本、驱动信息与扩展/特性支持情况，用于排查 26.2 及以上版本无法使用 Vulkan 的问题。行尾会显示上次检测结果的摘要。
- **禁用 Vulkan 兼容性检测**（默认关闭）：开启后，启动 26.2 及以上版本时跳过检测与相关提示。

## 启动检查

以下开关默认全部关闭，除非明确知道用途，否则不建议开启：

| 设置项 | 作用 |
|---|---|
| 不检查游戏完整性 | 跳过游戏文件完整性检查以加快启动 |
| 不自动恢复整合包文件 | 不自动补全整合包缺失文件（含被删除或更新的模组） |
| 不检查 [JVM](window:/term/JVM) 兼容性 | 跳过 JVM 有效性检查 |
| 不检查模组兼容性 | 跳过模组兼容性检查 |
| 输出调试[日志](window:/term/日志) | 输出详细调试日志，便于排查问题 |

:::tip
遇到崩溃时，建议保持**输出调试日志**开启，然后通过「启动器设置 → 调试 → 导出启动器日志」或在游戏内日志面板获取日志。关闭各兼容性检查可能让问题在更晚的阶段才暴露，反而更难排查。
:::

## 高级启动参数

| 设置项 | 说明 |
|---|---|
| 游戏参数 | 附加给 Minecraft 的启动参数 |
| Java 虚拟机参数 | 附加的 JVM 参数 |
| 环境变量 | 传递给游戏进程的环境变量，每行一条 `KEY=VALUE` |

- 前两项可直接编辑，也可长按输入框打开大文本编辑对话框；
- 环境变量在启动游戏时逐条写入游戏进程环境；
- 参数填写错误会直接导致启动失败，不熟悉时请保持为空。
