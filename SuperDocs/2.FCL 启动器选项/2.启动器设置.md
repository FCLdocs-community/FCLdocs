# 启动器设置

启动器设置位于 **设置 → 启动器设置**。这里只调整**启动器自身**的界面与行为，不改变游戏内的运行参数（游戏相关参数见[全局游戏设置](/SuperDocs/FCL%20启动器选项/全局游戏设置)与各版本的版本设置）。

## 语言

切换启动器界面语言，可选：

| 语言 |
|---|
| 跟随系统语言 |
| English |
| 简体中文 |
| Русский |
| Português (Brasil) |
| فارسی |
| Українська |
| Deutsch |
| 繁體中文（香港） |
| 日本語 |
| Türkçe |
| 繁體中文（台灣） |

选择后立即重建界面生效，无需手动重启。

## 启动器更新

| 按钮 | 作用 |
|---|---|
| 检测 | 手动检查启动器是否有新版本 |
| 更新内容 | 查看当前版本的更新[日志](window:/term/日志) |

检查失败时会[弹窗](window:/term/弹窗)提示原因（通常是网络问题）。更新源与[下载](window:/term/下载)源设置无关，由 FCL 的更新服务提供。

## 调试

| 按钮 | 作用 |
|---|---|
| 导出启动器日志 | 将启动器运行日志导出为文件（`fcl-exported-logs-<时间>.log`），用于反馈问题 |

导出位置为共享[目录](window:/term/文件夹)的上一级，即 **`内部存储/FCL/`**（文件名为 `fcl-exported-logs-<时间>.log`）。反馈问题前先导出日志，能显著提高排查效率。

## 请求麦克风权限

请求系统的录音[权限](window:/term/权限)，供游戏内语音聊天类[模组](window:/term/mod)使用。若已授权则不会重复请求；若系统已标记为「不再询问」，会跳转到应用的权限设置页面。

## 自动关闭

开启后，启动游戏时自动退出启动器。代价是游戏[崩溃](window:/term/崩溃)时不再显示启动器的崩溃分析界面，因此不建议在排查问题时开启。

## 主题与外观

### 主题模式

可选 **跟随系统** / **亮色模式** / **暗色模式**，默认为跟随系统。切换后立即生效。

### 主题色

分为四行，每行提供三种操作：

| 操作 | 说明 |
|---|---|
| 重置 | 恢复默认颜色 |
| 从背景图片提取 | 使用当前背景图的主色调/辅助色（Android Palette 取色） |
| 设置 | 打开取色器自定义颜色 |

四行分别是：**主要主题色（浅色/深色）**、**次要主题色（浅色/深色）**。次要主题色用于强调、按压态等辅助场景。

### 主题色透明度

调整主题派生色（卡片、按压态等）的透明度，范围 0%–100%。0% 完全透明，100% 完全不透明；该值独立于主要主题色本身。

### 背景

| 设置项 | 支持格式 | 说明 |
|---|---|---|
| 亮色模式启动器背景图片 | png / jpg / jpeg | 最大[分辨率](window:/term/分辨率) 5120×5120 |
| 暗色模式启动器背景图片 | png / jpg / jpeg | 最大分辨率 5120×5120 |
| 启动器背景（视频） | mp4 | 动态视频背景 |
| 视频背景音量 | —— | 0%–100% |

前两行提供「重置 / 设置」；视频背景同样支持重置，设置时选择 mp4 文件。

## 游戏内显示

| 设置项 | 作用 |
|---|---|
| 鼠标图片 | 自定义游戏内鼠标指针样式，支持 png / gif |
| 菜单键图标 | 自定义游戏内悬浮菜单的图标，支持 png / gif |
| 自定义启动器信息 | 游戏内显示的启动器名称，默认 `Fold Craft Launcher/<版本号>` |

## 界面与交互

| 设置项 | 作用 |
|---|---|
| 全屏 | 忽略屏幕刘海区域，全屏显示启动器 |
| 关闭皮肤模型阅览 | 关闭主界面的皮肤模型展示 |
| 动画速度 | 调整界面动画时长，范围 1–20，界面按 ×100 显示（如 8 显示为 800），数值越大动画时长越长、动画越慢 |
| 允许在崩溃界面[截图](window:/term/截图)/录屏 | 允许在本已禁止截图的崩溃界面继续截图或录屏 |

## 触控

以下两项用于配合 **TouchController** 模组：

| 设置项 | 作用 |
|---|---|
| 震动时长 | 按键振动时长，范围 20–500 毫秒 |
| 禁用全屏输入 | 关闭全屏输入模式（部分设备需要），默认为开启 |

## 下载

| 设置项 | 选项 | 说明 |
|---|---|---|
| 版本列表源 | 自动 / 官方源 / 镜像源 | 获取 Minecraft 版本清单的来源 |
| 文件下载源 | 自动 / 官方源 / 镜像源 | 下载游戏文件、模组等的来源 |
| 下载并发数 | 1–128 | 下载任务的并发线程数 |

- 下载源选「自动」时由启动器按网络环境选择；
- 「自动选择并发数」勾选后，并发数取默认值 `min(CPU 核心数 × 4, 64)`；取消勾选后可手动调整滑块。

## 模组缓存

「清除」按钮会清空 CurseForge 与 Modrinth 的查询结果[缓存](window:/term/缓存)。清除后再次浏览模组列表会重新联网获取数据，适用于缓存过期或数据异常的情况。

> 游戏运行参数（[Java](window:/term/Java)、[内存](window:/term/内存)、[渲染器](window:/term/渲染器)、Vulkan [驱动](window:/term/驱动)等）请见[全局游戏设置](/SuperDocs/FCL%20启动器选项/全局游戏设置)。
