# 帮助和关于

「关于」位于 **设置 → 关于**（本节标题沿用「帮助和关于」）。页面分为三部分：顶部的说明文字，以及下方的链接组（官方、社区、协议）。遇到问题时如何求助，一并放在本节末尾。

页面顶部是一段说明文字，内容为：

- FCL 由 **FCL-Team** 基于 **HMCL** 的核心功能、使用 **PojavLauncher** 后端开发；
- 项目借鉴并引用了 PojavLauncher 与 Boat 的部分源码，因此**分发该软件需遵循 GPL-v3 协议**。

## 用户协议与隐私政策

这两项以[弹窗](window:/term/弹窗)形式显示文档内容，文档随[安装包](window:/term/安装包)分发，按当前界面语言显示，该语言缺失时回退英文。

- **用户协议**：首次启动 FCL 时需要阅读并同意。
- **隐私政策**：同样在首次启动时确认。
- 同意状态按**协议版本号**记录；协议内容更新后版本号递增，所有用户需在下次启动时重新确认。
- 隐私政策弹窗内提供 **撤回同意**：确认撤回后会清除同意记录并立即退出应用，下次启动重新进入确认流程。该操作**不会删除本机已有数据**（游戏、[存档](window:/term/存档)、设置均保留）。

## 遇到问题如何求助

建议按以下顺序处理：

1. **先查文档**：本站 [FAQ](/FAQ) 与「[报错](window:/term/报错)解决」章节覆盖了常见启动失败、[模组](window:/term/mod)冲突、渲染错误等问题；
2. **导出[日志](window:/term/日志)**：在 **设置 → 启动器设置 → 调试 → 导出启动器日志** 生成日志文件；游戏[崩溃](window:/term/崩溃)时还应提供游戏日志（游戏内菜单 → 日志）；
3. **带上信息反馈**：向社区反馈时，附上 **FCL 版本、设备型号、游戏版本、完整日志与复现步骤**，能大幅缩短排查时间；
4. **更新启动器**：在 **设置 → 启动器设置 → 启动器更新** 中检查是否有新版本，部分问题已在新版本修复。

常用求助渠道：

| 渠道 | 用途 |
|---|---|
| QQ 群 | 玩家交流、问题求助 |
| Discord | 国际社区交流 |
| GitHub Issues | 提交 Bug 与功能建议 |
| 赞助 | 支持项目持续维护 |

> 游戏运行相关的设置说明见[全局游戏设置](/SuperDocs/FCL%20启动器选项/全局游戏设置)，启动器自身的外观与行为设置见[启动器设置](/SuperDocs/FCL%20启动器选项/启动器设置)。
