# 笨蛋MC链接

本站前面的教程只做一件事：帮你在电脑或手机上把服务端跑起来，让客户端能连进去。做到这一步，开服其实只完成了一半。

[服务器](window:/term/服务器)要长期开下去，还会遇到这些问题：

- 该选哪个[服务端核心](window:/term/服务器核心)？
- 怎么装[插件](window:/term/插件)、怎么写配置文件？
- 怎么让外网的朋友连进来，[公网 IP](window:/term/公网IP) 和[内网穿透](window:/term/内网穿透)怎么选？
- 玩家多了怎么优化、怎么防熊孩子？

这些内容本站不会展开。想系统学开服，推荐去看**笨蛋文档**。

## 笨蛋文档是什么

**笨蛋文档**（英文名 **NitWikit**，现在的站点名是 **Cubic Wiki**）是一份主要面向**高版本 [Java](window:/term/Java) 版**和**基岩版**服务器的开服指南。

它的名字来自 Minecraft 里的傻子村民「nitwit」，加上 Wiki 的后缀，组合成了 NitWikit。文档最初由「驿站」编写，后来由 8aka-Team、Cubic-Project 团队和六十多位贡献者共同维护，配套还有 B 站的《笨蛋级 MC 开服教程》视频。

站点定位很明确：**从零开始，手把手教你搭建和运营 Minecraft 服务器**，而且只讲高版本，不涉及远古核心。

## 站点里有什么

笨蛋文档按「引导 → Java → Bedrock → 关于」组织，Java 版部分大致包括：

- **准备工作**：什么是服务端、常用管理[指令](window:/term/指令)、安装 Java、配置[环境变量](window:/term/环境变量)、选文本编辑器。
- **搭建服务器**：选择服务端（插件端、[Mod](window:/term/mod) 端、混合端、[Folia](window:/term/Folia) 等）、安装与开启服务端、认识服务端[目录](window:/term/文件夹)结构、修改配置、客户端连接。
- **部署到生产环境**：购置服务器、申请公网 IP、内网穿透、把服务端长期挂在云上。
- **插件与玩法**：插件[下载](window:/term/下载)、YAML 配置、颜色代码、插件[前置](window:/term/前置模组)、汉化与常见问题。

基岩版部分则是另一套独立的开服流程。

## 什么时候该去看

- 已经能进服，但想认真运营一个长期服。
- 想搞清楚[插件端和 Mod 端](/SuperDocs/开一个属于自己的服务器/认识服务器核心)的区别，不知道该选哪个。
- 需要配置公网访问，但看不懂[端口](window:/term/端口)映射和[内网穿透](/SuperDocs/联机途径/内网穿透连接)。
- 遇到服务端[报错](window:/term/报错)，本站的「报错解决」覆盖不到。

如果只是想先在本机或手机上把服务器开起来，继续看本站的[电脑Windows开服](/SuperDocs/开一个属于自己的服务器/开服操作/电脑Windows开服)即可，遇到瓶颈再去看笨蛋文档。
