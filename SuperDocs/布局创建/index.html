理解按键

手机为什么需要按键映射​

Minecraft Java 版读取的是键盘和鼠标输入，这一步由 LWJGL 完成。手机没有这些设备，所以启动器需要把屏幕上的触摸操作转换成游戏认识的键码。

FCL 提供的是一整套可编辑的控件系统：屏幕上的按钮、方向键、摇杆都可以自己增删改，按下后输出什么键、在什么情况下显示，也都可以配置。

本页只讲这套系统的概念，具体操作放在后面的教程里。

三个层级​

FCL 的按键系统分为三层：

  • 布局：界面中也叫「控制布局」「布局方案」，是一套完整的按键配置。
  • 控件组：布局内部的分组。
  • 控件：屏幕上的具体元素，分为按键和方向控制键。

一个布局包含多个控件组，一个控件组包含多个按键和方向控制键。游戏运行时只会使用一个布局，但布局里的多个控件组可以同时显示。

布局​

布局是顶层单位，每个布局有名称、作者、版本和描述。它相当于一份独立的配置文件，可以创建、复制、导入、分享、上传和下载。

同一时间只会生效一个布局。可以为每个游戏版本单独指定布局，也可以在游戏内临时切换。

控件组​

控件组是布局内部的分组，用来管理控件。每个组有名称和初始可见性。

初始可见性决定游戏启动时这个组是否显示。隐藏的组不是永远消失：按键事件可以绑定控件组，按下时重新显示或隐藏它。

控件组的排列顺序就是层级。列表越靠下的组，显示层级越高；两个组重叠时，靠下的组会盖住靠上的组，触摸也会优先交给靠下的组。

控件​

控件是真正显示在屏幕上的元素，分为两类。

按键​

按键由三部分组成：

  • 基本信息：显示文本、可视性、坐标、尺寸、样式。
  • 控件事件：按压、长按、点击、双击时分别做什么。
  • 样式：按键的外观，来自公共样式库。

显示文本只是按钮上写的字，和按下后输出的键值没有关系。一个写着「跳跃」的按钮，完全可以在按下后输出 E。

可视性决定控件在什么情况下出现：总是可见、在游戏内可见，还是只在打开菜单时可见。

坐标是相对屏幕的百分比，左上角为 0%, 0%。尺寸可以用百分比（以屏幕宽或高为参照），也可以用 dp 作绝对单位。

控件事件才是功能所在。一次触发可以同时做多件事，例如输出键值、打开菜单、切换控件组显隐。四种触发方式互相独立，可以分别配置。

方向控制键​

方向控制键用来控制移动，外形分十字键和摇杆两种。它和按键共享基本信息的概念，但尺寸固定为正方形。

方向控制键的专属事件是四个方向的键值，默认对应 W、S、A、D。摇杆样式还可以配置跟随方式、死区、前进锁和双击中心潜行。

一个方向控制键是十字键还是摇杆，由它使用的样式决定，控件本身不单独保存这个选择。

样式​

按键样式和方向控制键样式是两套独立的公共样式库。控件按名称引用样式，而不是各自保存一份外观。

因此修改一套样式，会影响所有正在使用它的控件。样式只改变外观，不影响功能。

事件与样式的区别​

  • 事件决定按下后发生什么，是功能。
  • 样式决定看起来什么样，是外观。

两者互不影响。改了按钮颜色不会改变它输出的键，换了键值也不会改变外观。
