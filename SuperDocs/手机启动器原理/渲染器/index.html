渲染器

在手机 Minecraft Java 版语境下，"渲染器"指 OpenGL 的实现方式，即用什么办法把游戏的 OpenGL 调用转换为手机 GPU 能执行的指令（概念见什么是图形渲染器）。本节是实操向内容：FCL 中每个渲染器的定位、适用场景与扩展机制。

为什么需要多个渲染器​

没有一种渲染器能覆盖所有组合。Minecraft 版本跨度大（1.7 至 26.x），着色器复杂度不断上升；手机 GPU 又分 Adreno、Mali、PowerVR 等流派。因此 FCL 内置五个渲染器，并支持插件扩展。

表中数值取自 FCL 源码注册信息。Zink 与 Krypton Wrapper 对内门控至 26.3-snapshot-3，但面向用户展示的兼容上限为 26.2。

各渲染器说明​

Holy-GL4ES：上游是 HolyGL4ES（ptitSeb gl4es 面向 Minecraft 的修复分支），libgl4es_114.so 对应 gl4es 1.1.4 系列。其核心能力是**固定管线模拟（FPE）**：在 GLES2 上模拟老版本 Minecraft 使用的 OpenGL 1.x 固定管线。着色器转换能力弱，这是它兼容上限为 1.21.4 的原因。

VGPU：FCL 于 2023 年加入的轻量方案，用软件方式补齐固定管线，只覆盖 1.16.5 及更早版本，特点是占用小、兼容老版本与老模组。

Zink：出自 Mesa 的官方实现，将 OpenGL 编译为 Vulkan。能力上限高（向游戏声明 OpenGL 4.6 支持），但依赖 Vulkan 驱动质量——Adreno 设备配合 Turnip 驱动效果明显，Mali 设备则取决于系统驱动。带着色器缓存。

Krypton Wrapper（NG-GL4ES）：NG-GL4ES 是 gl4es 的现代化分支，用 glslang + SPIRV-Cross 提高着色器转换能力，走 GLES3 路线，兼容上限至 26.2，是当前默认渲染器。

MobileGlues：MobileGlues 是社区项目，专为 Minecraft 优化，支持 Sodium、大多数 Iris 光影以及 Create 等自绘 mod，可选配 ANGLE 二层。FCL 自 2026 年 10 月起将其内置，并提供运行时设置界面（环境变量、MultiDraw 方案等），26.x 推荐使用。

渲染器插件机制​

自 2024 年 10 月起（提交 Feat[Plugin]: renderer plugin），FCL 将渲染器插件化，渲染支持可以脱离启动器本体更新。参考 FCLRendererPlugin 模板：

  • 插件是一个普通 APK，在 manifest 的 meta-data 中声明 fclPlugin=true 以及渲染器名称、描述、环境变量；
  • 新版（v2）格式通过插件内 JSON 资源声明可配置项（下拉选择 / 自定义输入 / 开关），FCL 在渲染器"齿轮"对话框中直接生成配置界面，配置持久化到启动器 DataStore；
  • 启动时，FCL 将插件解压出的库目录注入 LD_LIBRARY_PATH，并按插件声明的 DLOPEN、LIB_MESA_NAME、POJAVEXEC_EGL 等环境变量加载渲染库（源码 FCLauncher.addRendererEnvInner()）；
  • VirGL（gallium_virgl，配套 virgl_test_server）、Freedreno 等均通过此机制引入。

驱动插件：渲染器的地基​

对 Zink 这类走 Vulkan 的渲染器，效果取决于 Vulkan 驱动质量。系统驱动不理想时可自行更换驱动，参考 FCLDriverPlugin 模板：

  • 将开源 GPU 驱动的 .so（Adreno 的 Turnip：libvulkan_freedreno.so；Mali 的 panvk）打包为 APK 安装；
  • 在「版本设置 → 驱动」中选择后，FCL 将插件库目录作为 DRIVER_PATH 传入游戏进程，native 层的 linkerhook 拦截 Vulkan 加载器的 android_dlopen_ext，将系统驱动替换为插件驱动；
  • DRIVER_GPU 标明适配的 GPU 家族（adreno / mali / any），不匹配则回退系统驱动；
  • 若设备驱动存在功能缺口，FCL 的 vkshim 可自动包一层补齐（2026 年 11 月加入 Vulkan 设备检测与能力补全）。

SFPEW 是什么

SimpleFPEWrapper 是一层"兼容包装"：当某些新渲染后端不支持老版本的固定管线时，由它模拟补齐，使"新渲染器 + 老版本"也能组合。FCL 内置 MobileGlues 时默认启用。
