# 1. 游戏设置 (新手入门)

在 FCL 左侧边栏点击**扳手图标**，即可进入“游戏设置”页面。这里是决定你的《我的世界》能否顺利启动、流畅运行的核心区域。

建议新手在进行以下设置前，先确定**游戏版本是否下载好**，然后再回来针对该版本进行调整。

---

## 1.1 基础配置 (版本与环境)
*   **应用游戏特定设置**：**建议开启**。开启后，当前页面的所有设置将只对当前选择的例如“1.20.1”等版本生效，不会影响其他版本。
*   **版本图标**：点击右侧的**铅笔图标**可以修改启动器中显示的该版本图标。
*   **Java 版本**：新手保持 **“自动选择”** 即可。如果遇到莫名其妙的崩溃，可以点击右侧齿轮手动指定已安装的 Java 版本（FCL 通常会自动提供适配的 Java）。
*   **版本隔离**：**强烈建议开启**。开启后，该游戏版本或整合包的 Mod 与配置文件都会分开存放，以避免不同版本间的 Mod 冲突引发崩溃。（最好是在全局游戏设置里开启版本隔离，这类设置在左侧下边的齿轮图标里）

## 1.2 内存分配 (最重要的一步)
游戏能否流畅运行，很大程度上取决于分配的内存大小。
*   **自动分配内存**：**建议新手勾选**。对于新手来说很方便，不过有时会自动分配过少或过多导致卡顿。**那么因此建议手动设置了**。（请勿拉满，因为这里分配的是手机运存，最大概率导致崩溃）
*   **最低内存分配**：通过下方滑块设定。例如`2048MB` 约为 2GB。
*   **配置建议**：
    *   玩**原版/小模组**：分配 2048MB ~ 4096MB (2G~4G)。
    *   玩**大型整合包**：分配 6144MB ~ 8192MB (6G~8G)，甚至更多。
    *   **仅供参考，分配多少看情况分配，不知道怎么分配可以参考以上**
    *   **请你注意**：不要分配超过你手机总内存的一半以上，否则会导致手机后台被杀或极度卡顿。请以你拖动的滑块数值为准。

## 1.3 服务器设置
*   **服务器地址**：如果你只想玩某个特定的服务器（如 Hypixel），可以把服务器 **IP 地址和端口**填入此处。开启游戏后会自动进入该服务器，无需手动输入。

## 1.4 控制与图形 (手机玩家重点)
*   **控制**：默认即可，点击齿轮可自定义按键布局。
*   **基岩版触控手势**：**建议开启**。开启后游戏的操作方式会更加贴合手机版《我的世界》，滑动旋转视角等操作会更顺手。
*   **图形后端**：保持 `default` 即可。此选项功能仅对26.2+生效，若您在玩 26.2-版本，建议保持默认设置，不要轻易改动。
*   **OpenGL 实现方式(渲染器)**：推荐使用 **`MobileGlues`**。对于高画质整合包，它能提供较好的渲染效率。不过MobileGlues供对1.17+生效，对于1.17-的可以使用MobileGL，当然高版本也可以用此渲染器，因为据我所知这MobileGL是通用的，或者是你也可以选择Kryton Wrapper以及其他渲染器。
*   **强制渲染器在大核上运行**：**建议开启**。这能让游戏强制调度手机的高性能核心来渲染，能显著提升帧率。
*   **使用系统 Vulkan 驱动 & Vulkan 驱动**：如果手机支持（特别是高通的骁龙芯片），推荐开启并选择 **`Turnip`** 驱动。Vulkan 渲染效率通常比 OpenGL 更高，能明显降低发热和提升帧率。

## 1.5 兼容性与调试 (排查崩溃)
*   **不检查游戏完整性 / 不检查 JVM 兼容性 / 不检查模组兼容性**：正常情况下**建议关闭**。这能帮你先筛除因文件损坏导致的崩溃。只有在遇到报错又无法解决时，才尝试打开这些选项强制跳过检查。
*   **输出调试日志**：**建议开启**。如果遇到游戏闪退，可以在日志中找到崩溃原因（`crash-log`），方便发到社区求助。

## 1.6 高级参数
*   **游戏参数 / Java 虚拟机参数 / 环境变量 / 自定义 UUID**：**新手保持默认**。随意修改这里可能会导致无法启动。只有懂代码或解决特定疑难杂症时才需要改动。
*   **强制设置分辨率**：**实验性选项，谨慎使用**。如果你想自定义游戏窗口的分辨率（如 720p、1080p）来获得更好的性能或显示效果，可以开启。

---
**💡 新手配置速记口诀**：
> 勾选**隔离**，手设内存；
> 开**触控**和**大核**，选 **Vulkan/Turnip**；
> 日常不勾**跳过检查**，找不到原因再开**日志**。
