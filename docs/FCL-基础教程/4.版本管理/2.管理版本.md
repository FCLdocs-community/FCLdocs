# 管理版本
管理版本可以方便地浏览、操作游戏版本，例如浏览截图文件、重命名版本等

# 打开管理版本
:::note 前提
你需要**安装至少一个版本**才能使用管理版本
:::
1. 在启动器主页点击“**扳手🔧**”
2. 点击上方第二个“**管理版本**”

# 管理版本的功能

## 浏览类
在管理版本的左侧列表，可以浏览游戏文件

:::note 文件管理器
使用上述浏览功能时，会打开FCL的文件管理器，如图：
:::

- 上传日志：上传日志能够将最近一次的游戏日志上传到[LogShare](https://logshare.cn/)

- 其他浏览功能
    - 浏览FCL日志文件夹：能够浏览FCL的启动和游戏日志，即`FCL/log/`
    - 浏览游戏文件夹：浏览当前版本的**根目录**，即`.minecraft/versions/[版本]/`
    - 浏览模组文件夹：浏览当前版本的**模组**，即`.minecraft/versions/[版本]/mods/`
    - 浏览配置文件：浏览当前版本的模组的**配置**，即`.minecraft/versions/[版本]/config/`
    - 浏览资源包文件夹：浏览当前版本的**资源包**，即`.minecraft/versions/[版本]/resourcepacks/`
    - 浏览光影文件夹：浏览当前版本的**光影包**，即`.minecraft/versions/[版本]/shaderpacks/`
    - 浏览截屏文件夹：浏览当前版本的**截屏文件**，即`.minecraft/versions/[版本]/screenshots/`
    - 浏览存档文件夹：浏览当前版本的**存档文件夹**，即`.minecraft/versions/[版本]/saves/`



## 操作类
- 更新整合包：更新整合包到当前游戏版本的最新版
- 重命名版本：将当前版本文件夹命名为新的名称
- 复制游戏实例：复制当前版本为新的版本
:::note 复制存档
勾选“复制存档”选项后，FCL会将当前版本连带存档文件一同复制到新的版本
:::
- 更新资源文件：更新`.minecraft/assets/`内的资源文件
- 删除所有库文件：删除`.minecraft/library/`内的所有库文件
- 清理游戏日志：删除当前版本的log文件夹，即删除`.minecraft/versions/[版本]/logs/`
- 导出整合包

导出整合包功能可以将当前版本打包为可被其他启动器导入的整合包

    1. 点击导出整合包
    2. 选择导出格式，建议选择MCBBS整合包标准
    3. 编辑整合包基础信息，点击下一步
    4. 选择整合包导出的路径如：`.minecraft/`
    4. 勾选需要导出的内容，取消勾选不导出的内容
    5. 点击下一步导出整合包，等待导出完成后点击确定完成导出
