# 管理模组
FCL提供了较为方便的模组管理功能，比如：禁用/启用模组、删除/添加模组

# 打开管理模组
1. 在启动器主页点击“**扳手🔧**”
2. 点击上方第二个“**管理模组**”

# 管理模组的功能

## 启用/禁用模组
在管理模组页面的模组列表中看到当前版本已安装的所有模组。
在每一个模组选项卡的**左侧方框**，勾选代表**启用**（默认启用），取消勾选代表**禁用**

## 模组详情
在每个模组选项卡的右侧，有详情按钮（“i”），点击弹出模组详情窗口。
点击详情窗口左下角的“官方页面”即可用浏览器跳转到模组的官方页面

## 搜索模组
你可以用搜索模组功能来搜索模组，适合大型整合包的模组管理。
搜索功能支持使用**模组名**和**模组加载器**搜索

## 筛选模组
在管理模组页面中，左侧的上方两个**可勾选选项**可以筛选已禁用和已启用的模组

## 添加模组
在左侧第一个按钮处，点击“添加模组”会打开FCL内置的文件管理器，在文件管理器中跳转到模组所在的路径，选定模组并确定即可将模组导入至当前版本


## 检查更新
在左侧第二个按钮处，点击“检查更新”开始检查当前版本所有模组的更新

检查更新完成后会跳转到模组更新页面，
上半部分是有可更新版本的模组，你可以勾选模组以对该模组进行更新操作

下面是更新选项，可以对模组进行更新操作
- 导出：导出功能可以将当前可更新模组列表的详细信息导出为**CSV表格**并保存到**FCL/目录**中
- 更新：将模组更新到新版本，但会保留旧版本的模组以方便以后将模组**回退为旧版本**，但旧版本的模组会**占用一定空间**
- 更新（不保留旧版本）：将模组更新到新版本，但**不会保留旧版本的模组**，可节省一定空间
- 取消：取消更新操作并返回返回到模组管理页面
