# FCL 全局游戏设置

> 本文档基于 FCL（FoldCraftLauncher）Android 端的全局游戏设置界面整理。所有设置会**同时影响**该启动器内安装的所有游戏版本，除非你在具体版本设置里单独设置。

## 1. Java 运行环境与版本隔离

*   **Java 版本**
    *   *功能说明*：选择用于运行 Minecraft 的 Java 环境。FCL 内置了适配手机的 JRE。
    *   *当前选择*：`自动选择`
    *   *详细建议*：`自动选择` 通常是最稳妥的，它会根据你安装的 Minecraft 版本（如 1.16.5、1.20+）自动匹配最合适的 Java 版本。只有当出现 `Java 版本不匹配` 的崩溃时，才建议手动切换到具体的 Java 8 或 Java 17（FCL 会提供图标供下载）。
    
*   **版本隔离**
    *   *功能说明*：让每一个 Minecraft 版本的 `mods`、`config`、`saves` 等文件夹单独存放，互不干扰。
    *   *当前选择*：`开启` (蓝色)
    *   *详细建议*：**强烈建议保持开启**。如果你同时玩原版、模组版和光影版，开启隔离可以防止不同版本的 Mod 冲突，也方便单独管理各个存档。

## 2. 游戏内存 (RAM) 分配

*   **自动分配内存**
    *   *功能说明*：由启动器根据手机当前空闲内存动态计算分配。
    *   *当前选择*：`已勾选`
    
*   **最低内存分配**
*   **⚠️ 详细建议与避坑指南**：
    *   **不要盲目依赖“自动分配”**：对于总内存 7.2GB 的手机，系统本身会吃掉 2~3GB。自动分配有时很保守，或者分配不足导致游戏卡顿。
    *   **手动配置推荐**：建议**取消勾选“自动分配”**，改为手动设定一个固定值。基于你 7.2GB 的总内存，推荐分配到 **3GB~4GB (3072MB~4096MB)**。
    *   **留有余地**：千万不要把内存拉满（比如拉到 6GB），否则会触发手机系统杀后台，导致游戏突然闪退或手机极度卡顿。通常给系统预留 2GB 以上是安全的。

## 3. 启动自动加入服务器

*   **服务器地址**
    *   *功能说明*：输入 IP 地址，点击启动游戏后，会自动连接到对应服务器。
    *   *详细建议*：如果你常玩某个固定的生电或小游戏服务器，可以直接填入 IP，省去进游戏后手打 IP 的步骤。

## 4. 控制与图形渲染

*   **控制**
    *   *功能说明*：选择屏幕按键布局预设。
    *   *详细建议*：如果默认按键适应不了，可以点右侧的 `齿轮（设置）` 进入自定义界面，自由调整攻击、跳跃、潜行等按键的大小和透明度。
    
*   **基岩版触控手势**
    *   *功能说明*：使用类似原版基岩版的滑动/长按等逻辑。
    *   *详细建议*：**建议开启**，可以提升移动端操作的顺滑度。部分喜欢 PC 端精确点击操作的习惯可能不适应，可依个人习惯开关。
    
*   **图形后端 (仅对 26.2+ 生效)**
    *   *功能说明*：引擎渲染的底层接口。
    *   *当前选择*：`default`
    *   *详细建议*：保持 default 即可。若遇到某些光影加载失败或渲染错误，可以尝试在此切换其他后端。
*   **OpenGL 实现方式 (渲染器)**
    *   *功能说明*：决定是用 OpenGL 还是 Vulkan 来绘制游戏画面。
    *   *当前选择*：`Krypton Wrapper (OpenGL 3.1+, 内置的)`
    *   *详细建议*：
        *   **推荐使用kw**：目前稍成熟、兼容性好的选项，对大多数骁龙/天玑/麒麟芯片都能很好地工作（虽然说是停更了），**如果遇见渲染问题可尝试切换其他渲染器**。
*   **强制渲染器在大核上运行**
    *   *功能说明*：强制 CPU 的大核心（Cortex-A7xx, X系列）来负责渲染器的计算。
    *   *详细建议*：**建议开启**。开启后能显著减少卡顿（尤其在加载区块时），但随之而来的缺点是**手机发热会增加、耗电加速**。用高性能换取流畅度。
*   **使用系统 Vulkan 驱动** & **Vulkan 驱动**
    *   *功能说明*：开关开启表示使用 GPU 的 Vulkan 渲染管线；下方的下拉框指定具体驱动。
    *   *详细建议*：
        *   **Turnip** 是著名的开源高性能 Vulkan 驱动，**特别适合高通骁龙（Adreno GPU）芯片**。如果是骁龙 865、870、8Gen 系列，开启 Turnip 并搭配 Iris/Oculus 光影，流畅度会大幅提升。
        *   如果是联发科（Mali GPU）或麒麟芯片，使用 Turnip 可能会崩溃，此时**强烈建议将 Vulkan 驱动切换为 系统默认**，保持“使用系统 Vulkan 驱动”即可。

## 5. 启动检查与调试

*   **不检查游戏完整性 / 不检查 JVM 兼容性 / 不检查组件兼容性**
    *   *当前选择*：三个开关**全部为关闭状态**（灰色）
    *   *详细建议*：**强烈建议保持关闭**。这些是安全保障。开启后可能会跳过 Mod 兼容性检测，导致进入游戏后直接黑屏或崩溃，排查难度极大。
    
*   **输出调试日志**
    *   *详细建议*：**游戏经常崩溃的玩家建议保持开启**。如果遇到闪退，去 FCL 的“日志”面板查看，这里会记录崩溃原因（如：缺少前置 Mod、Java 版本不对等），方便自行解决或向作者求助。

## 6. 高级启动参数

*   **游戏参数**
    *   *功能说明*：传递至 Minecraft 启动器的参数。普通玩家无需更改。
    
*   **Java 虚拟机参数**
    *   *功能说明*：用于设置 JVM 的底层参数，极其硬核。
    *   *进阶建议*：对于内存较大的手机，如果手动分配内存后仍感觉 GC（垃圾回收）卡顿，可填入 `-XX:+UseG1GC` 使用 G1 垃圾回收器，或 `-XX:+DisableExplicitGC` 禁用显式 GC 调用。**新手千万别乱填，极易导致游戏无法启动**。
    
*   **环境变量**
    *   *功能说明*：设置系统环境变量，主要用于某些特殊 Mod 需要读取特定的系统路径。
    *   *详细建议*：通常留空。
    
*   **自定义 UUID**
    *   *功能说明*：强制指定玩家的 UUID（离线验证下生效）。
    *   *详细建议*：如果你玩离线版，且使用了某些依赖 UUID 判定玩家的皮肤系统，可以在此填入特定的 UUID，否则无需设置。

## 7. 实验性功能

*   **强制设置分辨率**（实验性选项，谨慎使用）
    *   *当前选择*：`关闭`
    *   *详细建议*：**务必保持关闭！** 截图里也打上了“谨慎使用”的标签。强行修改屏幕渲染分辨率极可能导致画面比例失调、按键错位，甚至直接黑屏。除非官方特殊说明，普通用户切勿触碰。
