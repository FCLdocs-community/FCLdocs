# 创建存档

启动游戏后，等待加载至标题画面，点击**单人游戏**即可进入世界管理界面。

## 创建新的世界

初次进入时列表为空。你要点击底部**创建新的世界**，进入创建界面。

### 世界名称
输入任意名称（支持中文），仅用于列表显示，不影响游戏内容。

### 游戏模式

| 模式 | 特点 |
|------|------|
| **生存模式** | 需要收集资源、维持生命值和饥饿值、躲避怪物 |
| **创造模式** | 无限资源、可飞行、无敌，专注于建造 |

> 建议：完全没接触过 Minecraft 的小白，可以先开一局**创造模式**熟悉操作和方块，之后再玩生存。

### 难度（仅生存模式）

- **和平**：不生成怪物，生命自动恢复
- **简单 / 普通 / 困难**：怪物伤害和数量递增

新手推荐**简单**起步。

### 更多世界选项

点击**更多世界选项…**可展开额外设置：

| 选项 | 说明 | 建议 |
|------|------|------|
| **允许作弊** | 开启后可在游戏内输入指令（如切换模式、传送） | 新手建议开启，方便学习和调试 |
| **奖励箱** | 出生点附近生成一个装有基础物资的箱子 | 生存模式建议开启 |
| **生成结构** | 控制村庄、要塞等结构是否生成 | 保持开启 |
| **世界类型** | 默认 / 超平坦 / 巨型生物群系 / 放大化 | 新手保持**默认** |
| **种子** | 输入特定字符串生成固定地形，留空则随机 | 想复现特定地形时再填写 |

> 种子相当于地图的“身份证号”。同一串种子在不同 Minecraft 版本下，生成的地形可能不同。

### 创建世界

确认设置后，点击**创建新的世界**。游戏开始生成地形，等待进度条走完即可进入。

## 自动保存与退出

Minecraft 采用自动保存，无需手动操作：

- 游戏过程中定期自动保存
- 按 Esc → **保存并退出**回到标题画面时自动保存

> ⚠️ 保存过程中请勿强制关闭 FCL 或杀后台，否则可能导致存档损坏。

## 快速上手建议

1. 第一局先开**创造模式**，熟悉移动、跳跃、破坏/放置方块。
2. 熟悉后再新建一个**生存模式**世界，开启**奖励箱**和**允许作弊**。
3. 遇到危险时可以按 Esc 暂停。
