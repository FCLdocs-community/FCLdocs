# MCJava版加入服务器教程

## 第一步：进入多人游戏界面

在Minecraft标题画面中，点击 **`多人游戏`**按钮。

## 第二步：添加服务器

进入多人游戏界面后，你会看到已保存的服务器列表（如果是第一次进入则为空）。

1. 点击右下角的 **`添加服务器`**（Add Server）按钮。

### 填写服务器信息

在弹出的窗口中填写以下信息：

| 项目 | 说明 | 示例 |
|------|------|------|
| **服务器名称** | 随便起，方便自己识别 | 我的生存服 |
| **服务器地址** | 服务器 IP 或域名 | `play.example.com` 或 `192.168.1.100:25565` |

> 💡 **地址格式提示**：
> - 如果服务器使用默认端口 `25565`，只需输入 IP/域名即可。
> - 如果使用了非默认端口，需要加上端口号：`IP:端口`，例如 `mc.server.com:25566`。

2. 填写完成后，点击 **`完成`**（Done）。"

## 第三步：连接服务器

1. 回到多人游戏列表，你会看到刚刚添加的服务器。
2. 选中该服务器，点击 **`加入服务器`**（Join Server）按钮。
3. 等待连接，如果看到世界加载画面，说明连接成功！

## 常见问题排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| **无法解析主机名** | 地址输入错误 | 检查 IP/域名是否拼写正确 |
| **连接超时** | 网络不通或服务器未开启 | 确认服务器在线，检查防火墙/网络 |
| **不兼容的 FML 模组服务器** | 客户端缺少必要模组 | 向服主索要模组包并安装 |
| **无效会话** | 正版验证失败 | 确认使用正版账号登录；或服主关闭了正版验证但你用了正版 |
| **版本不兼容** | 客户端与服务器版本不一致 | 切换至服务器要求的游戏版本再试 |

## 快捷操作

- **刷新列表**：点击多人游戏界面右上角的 🔄 刷新按钮。
- **编辑信息**：选中服务器 → 点击 **`编辑`**（Edit）。
- **删除服务器**：选中服务器 → 点击 **`删除`**（Delete）。
- **直接连接**：点击 **`直接连接`**（Direct Connection），无需保存即可临时加入一次。

## 总结流程图

启动游戏 → 点击"多人游戏" → 添加服务器 → 输入地址和名称  → 完成 → 选中服务器 → 加入服务器 → 开始游玩！

:::tip
部分服务器需要预先安装指定模组（Mod）或资源包，请务必阅读服务器的 入服公告 或 QQ群 内的说明。
:::
