# 理解按键
在Android设备上操作Java版Minecraft并不像PC上那样直接，因为MCJE通过LWJGL来获取用户在键盘、鼠标的输入，所以需要将我们所输入的按键映射为能被LWJGL解析的键码。
因此FCL为我们提供了一整套的按键映射和控件/布局系统，我们可以通过这个系统来操作游戏。

# 理解控件基本概念
键位一般由**按键**、**方向控制键**和**控件组**组成，控件组包含按键和方向控制键。

## 控件组
控件组是**按键的集合**，它可以用来收纳多余不常用的按键，也可以方便地分组管理不同功能的按键。

控件组通常有以下属性：
- 名称：控件组的名称，在使用（关闭编辑模式）时不可见
- 初始可见性：控件组在初始状态（启动游戏）时是否可见
- 控件组层数（不可见）：控件组在哪一层。可以在`控件组>管理`中查看，
越下面的控件组越能覆盖上面的控件组。点击按键的覆盖区域，将触发下面控件组的按键

## 控键
“**控键**”是组成一套键位的**基本组成单元**，单个控件通常拥有以下属性：
- 控件基本信息：
    - 显示的文本：在控键上显示的文本内容，**只能决定显示的文本，不能决定映射的按键**
    - 可视性：决定在什么情况下显示该按键，例如：跳跃键的可视性改为“仅在游戏内可见”时，只有在进入世界后才会显示该键
    - 坐标：这个按键在屏幕的哪个位置，坐标位置采用**相对百分比坐标**，屏幕的左上角记为`X坐标=0%, Y坐标=0%`
    - 按键尺寸：控制着**按键的大小**
        - 尺寸类型：按键尺寸的参照物或单位
            - 百分比尺寸：以**屏幕宽或高为参照物**。值为100%时大小与参照物（屏幕宽/高）相同
            - 绝对尺寸： 以do为单位。一般情况下在任何Android设备上，**每dp对应的物理长度都是相等的**
    - 控件样式：按键长什么样
- 控件事件：
    - 指针跟随手指：当**按压按键并移动手指**时，鼠标指针（游戏内时为视角）是否跟随手指移动
    - 可移动：按键是否可以在**关闭编辑模式时移动**
    - 点击类型：
        - 按压：在按住按键时触发（**可保持触发**）
        - 长按：在长按按键时触发
        - 点击：在点击按键时触发（**不可保持触发**）
        - 双击：在双击按键时触发
    - 按键功能：
        - 自动保持：触发按键后自动保持触发，**无需一直按压**。例如：潜行键开启该功能后无需一直按压，点击即可潜行，再次点击即可取消潜行
        - 自动点击：触发按键后自动执行操作，类似于连点
        - 打开菜单：**呼出FCL游戏内菜单**，与FCL游戏内悬浮球效果等同
        - 切换触控手势模式：在建筑模式和战斗模式中切换（建筑模式在点击空白处时输出右键，战斗模式在点击空白处时输出左键）
        - 切换鼠标控制模式：在点击模式和拖动模式之中切换
        - 呼出输入法：打开手机的输入法，输入内容
        - 打开快捷输入：打开快捷输入窗口，点击文本即可输入文字
        - 发送文本：向游戏中发送一段预先制定好的文本
        - 输出键值（最常用）；**映射键盘或鼠标中的某个按键**，可同时输出多个键值
        - 切换控件组可视性：触发按键后**隐藏或显示选择的控件组**
        
## 方向控制键
方向控制键提供了更加便利的移动控制功能，方向控制键通常拥有以下属性：

- 控件基本信息：
    - 可视性：决定在什么情况下显示该按键，例如：将方向控制键的可视性改为“仅在游戏内可见”时，只有在进入世界后才会显示该键
    - 坐标：这个按键在屏幕的哪个位置，坐标位置采用**相对百分比坐标**，屏幕的左上角记为`X坐标=0%, Y坐标=0%`
    - 按键尺寸：控制着按键的大小
        - 尺寸类型：按键尺寸的参照物或单位
            - 百分比尺寸：以**屏幕宽或高为参照物**。值为100%时大小与参照物（屏幕宽/高）相同
            - 绝对尺寸： **以dp为单位**。一般情况下在任何Android设备上，**每DP对应的物理长度都是相等的**
    - 控件样式：按键长什么样
- 控件事件：
    - 方向键值：移动时输出什么键值
    - 潜行：与潜行相关
        - 双击中心潜行：打开后，双击方向控制键的中心将输出潜行键值，实现快速潜行
        - 潜行键值：双击中心潜行时将输出的键值

# 理解样式基本概念
按键样式是展现自己键位风格的重要功能，它能将按键变成各式各样的样子，也能用来区分不同的按键。
需要注意的是，按键样式只改变控件的外观，**不会改变功能**，但却极大得影响着观感和使用体验。

## 按键样式
按键样式常拥有以下属性：
- 名称（不显示）：你的按键样式的名称，能用来区分不同的样式，不在游戏内显示
- 状态：按键是否被触发
    - 常规状态：按键**没有被触发**时的状态，决定在按键没有被点击时的外观
    - 触发状态：按键**被触发**时的状态，决定在按键被点击时的外观
- 文本大小：按键上**显示文字的大小**，单位为**sp**，但显示的大小会**随着系统字体大小变大而变大**
- 边框宽度：按键外层边框的粗细，单位为**dp**
- 圆角半径：按键**四个角上圆角的半径**，单位为**dp**。数值越大圆角越大
- 颜色：以下均**以16进制表示**
    - 文本颜色：在按键上显示的**文本**的颜色，以16进制表示
    - 边框颜色：在按键**周围显示的边框**的颜色，以16进制表示
    - 填充颜色：整个按键**内部填充**的颜色，以16进制表示

## 方向控制键样式
按键样式常拥有以下属性：
- 名称（不显示）：你的按键样式的名称，能用来区分不同的样式，不在游戏内显示
- 方向控制键样式：
    - 十字键：
        - 按键间隔：按键之间的间隔，以整个方向控制键的宽度为参照物
        - 十字键内每一个按键将以什么样的样式显示
    - 摇杆：
        - 形状
            - 摇杆大小：方向控制键中间摇杆的半径，以**整个方向控制键的半径**为参照物
            - 背景边框宽度：方向控制键外层的边框的粗细，以dp为单位
            - 背景圆角半径：方向控制键外层的圆角的大小半径，以整个方向控制键为参照物，值为50%时为圆形
            - 摇杆边框宽度：方向控制键中间摇杆的边框的粗细，以dp为单位
            - 摇杆圆角半径：方向控制键中间摇杆的圆角的半径，以摇杆半径为参照物，值为50%时为圆形
        - 颜色：以下均**以16进制表示**
            - 背景边框颜色：方向控制键外层的边框颜色
            - 背景填充颜色：方向控制键外层背景的颜色，以16进制表示
            - 摇杆边框颜色：方向控制键中间摇杆的边框的颜色
            - 摇杆背景颜色：方向控制键中间摇杆的内部颜色
