# 进入存档

在标题画面点击**单人游戏**，即可看到你已经创建的所有世界。

## 选择世界

世界列表会显示每个存档的基本信息：

- **世界名称**：创建时填写的名字
- **模式图标**：生存 / 创造 / 冒险 / 极限的图标标识
- **最后游玩时间**：最近一次进入该世界的时间

点击任意一个世界，即可加载并进入。如果是刚创建的新世界，首次进入时会显示**生成地形中**的进度条，等待片刻即可。

## 认识游戏界面

成功进入世界后，你会看到以下界面元素：

### HUD（平视显示器 / Heads-Up Display）

- **十字准星**：屏幕正中央，用于瞄准和交互
- **快捷栏**：屏幕底部，显示当前手持的物品和可用的物品格子
- **生命值**（生存 / 冒险 / 极限模式）：快捷栏上方左侧的心形图标，共 10 颗心
- **饥饿值**（生存 / 冒险 / 极限模式）：快捷栏上方右侧的鸡腿图标，共 10 个鸡腿
- **经验条**：生命值和饥饿值下方、快捷栏上方的绿色长条，显示当前等级与经验进度

> 创造模式和旁观模式下不显示生命值、饥饿值和经验条。

### FCL 虚拟按键

屏幕上的触控按钮布局（可在 FCL 设置中调整）：

| 按键 | 功能 |
|------|------|
| **方向摇杆**（左下角） | 控制前后左右移动 |
| **跳跃**（右下角） | 点击跳跃，双击切换飞行（创造模式） |
| **潜行** | 缓慢移动，防止从方块边缘跌落 |
| **疾跑** | 快速移动，消耗饥饿值 |
| **攻击 / 破坏**（右侧） | 长按破坏方块，点击攻击生物 |
| **使用 / 放置**（右侧） | 点击放置方块，或与门、箱子等交互 |

> 提示：手指在屏幕空白区域滑动可以转动视角。

## 第一次进入世界该做什么

### 创造模式
- 点击屏幕下方的快捷栏选择方块
- 点击**使用 / 放置**按钮放置方块
- 双击**跳跃**进入飞行模式，再次双击退出
- 没有生存压力，先熟悉移动、视角和方块操作

### 生存模式
- 第一天建议：**找树 → 用手破坏木头 → 打开背包制作工作台**
- 夜晚会生成怪物，尽快用泥土或木头搭一个简易庇护所
- 按 Esc 可以暂停游戏（单人模式下时间停止）

## 退出与保存

需要退出时：

1. 按 Esc（或点击 FCL 的菜单按钮）打开游戏菜单
2. 点击**保存并退出**回到标题画面
3. 再从标题画面退出 FCL

> 存档会在退出时自动保存，游戏过程中也会定期自动保存。退出前请确保没有正在进行的操作（如正在破坏方块或打开界面）。

## 常见问题

:::note **Q：进入世界后很卡？**  
A：按 Esc 打开菜单 → **选项…** → **视频设置…**，将**渲染距离**调低（如 6-8 个区块），关闭**云**和**粒子效果**。
:::

:::note **Q：不小心把世界玩坏了怎么办？**  
A：如果之前没有备份，可以尝试在世界列表中点击该世界的**编辑**按钮，开启**允许作弊**，进入后使用指令恢复（如 `/gamemode creative` 切换创造模式自救）。
:::
