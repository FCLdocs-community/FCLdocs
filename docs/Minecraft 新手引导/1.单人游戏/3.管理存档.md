# 管理存档

在标题画面点击**单人游戏**后，你可以对已有世界进行多种管理操作。

## 世界列表操作

每个世界条目右侧都有按钮（或选中后底部出现）：

### 游玩
点击世界名称或**游玩**按钮，即可进入该世界。

### 编辑
点击**编辑**按钮，可以修改世界的各项属性：

| 设置项 | 说明 |
|--------|------|
| **世界名称** | 修改后在列表中显示的新名字，不影响文件夹名 |
| **游戏模式** | 可切换生存 / 创造 / 冒险模式（部分情况下需开启允许作弊） |
| **允许作弊** | 开启后可在游戏内输入指令 |
| **生成结构** | 控制是否生成村庄、要塞等结构 |
| **奖励箱** | 是否在世界出生点生成初始物资箱（创建后通常不可再改） |

> 注意：修改游戏模式前建议先开启**允许作弊**，否则部分选项可能无法调整。

### 删除
点击**删除**按钮，会弹出确认提示。确认后该世界将从列表中移除，**存档文件也会被删除**。

> ⚠️ 删除前强烈建议先备份！

## 复制世界

如果你想保留当前世界的某个状态，或者想用同一个地图开新档：

1. 在世界列表中选中该世界
2. 点击**编辑**按钮
3. 找到**复制世界**选项
4. 确认后，列表中会生成一个名称带序号（如「（1）」）的新世界

两个世界从此独立，互不影响。

## 重新创建（重建）

如果你想用**相同的种子**再开一个新世界（保留地形生成规则，不保留已有建筑和物品）：

1. 在世界列表中选中该世界
2. 点击**重建**（或「重新创建」/「用相同种子新建」）
3. 进入创建界面，种子栏已自动填入原世界的种子
4. 修改其他设置后创建

## 备份世界

推荐两种备份方式。

### 方法一：游戏内「创建备份」（最方便）

1. 在世界列表中选中目标世界
2. 点击**编辑**
3. 点击**创建备份**
4. 等待提示「备份完成」

备份会生成一个 `.zip` 文件，存放位置如下：

**公有目录：**
- 开启版本隔离：`/storage/emulated/0/FCL/.minecraft/versions/版本号/backups/`
- 未开启版本隔离：`/storage/emulated/0/FCL/.minecraft/backups/`

**私有目录：**
- 开启版本隔离：`/storage/emulated/0/Android/data/com.tungsten.fcl/files/.minecraft/versions/版本号/backups/`
- 未开启版本隔离：`/storage/emulated/0/Android/data/com.tungsten.fcl/files/.minecraft/backups/`

文件名示例：`2026-07-27_09-30-15_我的世界.zip`

编辑界面里通常还有 **「打开备份文件夹」** 按钮，可直接跳转到该位置。

### 方法二：手动复制世界文件夹

适合迁移到电脑、网盘或其他设备。

#### 世界（存档）实际位置

**公有目录：**
- 开启版本隔离：`/storage/emulated/0/FCL/.minecraft/versions/版本号/saves/世界名称/`
- 未开启版本隔离：`/storage/emulated/0/FCL/.minecraft/saves/世界名称/`

**私有目录：**
- 开启版本隔离：`/storage/emulated/0/Android/data/com.tungsten.fcl/files/.minecraft/versions/版本号/saves/世界名称/`
- 未开启版本隔离：`/storage/emulated/0/Android/data/com.tungsten.fcl/files/.minecraft/saves/世界名称/`

> 「版本号」请替换为你实际使用的版本或整合包名称。

#### 手动备份步骤

1. 完全退出游戏和 FCL
2. 用文件管理器进入上面的对应目录
3. 复制目标世界文件夹（或直接复制 `backups` 文件夹里的 zip）
4. 粘贴到安全位置（手机其他目录、电脑、网盘等）

恢复时把文件夹放回原来的 `saves` 目录，或把 zip 解压后放回即可。

> 小白提示：日常快速备份优先用游戏内的「创建备份」；重要进度建议再额外把整个世界文件夹或 zip 复制到公有目录/电脑。
