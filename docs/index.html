介绍

欢迎各位新人来看FCL教程

本教程专门为了方便各位理解而做的一个新手教程文档

前言​

或许有人好奇，我为啥要创建一个教学文档。

首先，网上的各个教程内容不同，所介绍的侧重点不同（比如有的教程重点介绍联机方法，有的教程重点介绍安装方法），这就导致当新手小白需要浏览多个视频和文章才能勉强掌握，比较耗费时间。

其次，大多接触 FCL 的玩家基本上是从网易我的世界转来的，由于网易我的世界的操作简单、游玩方便，导致这类玩家转入 FCL 会出现不适应的情况，遇到问题时又不懂得如何解决。

该文档的初衷是为了让新手小白逐渐适应 FCL 的操作方式，提升解决问题的效率，从而更好地游玩手机 Java。

Warning

由于 FCL 上手难度较大，如果你第一次接触 FCL，请认真并耐心地把该文档的"手机小白必看"、"FCL 的下载与安装"、"FCL 的使用"、"Minecraft 新手指引"看完。

该文档与其它教程不同的是，有"手机小白必看"和"进阶教程"的模块，前者是为没有计算机基础的玩家写的，后者是为有更多需求的玩家写的，努力让该文档做到"一条龙服务"的教程。

由于该文档创立不久，可能会出现缺漏与错误，也有可能在 FCL 版本更新后未能校正其内容。如有出现，欢迎大家通过GitHub或通过 QQ 群进行反馈。

运行环境​

FCL启动器 的运行环境要求：Android 8版本以上

Android 7 及以下安装时会提示"安装包损坏"，这是系统版本不符，并非安装包问题。

参考配置：

配置档位处理器内存存储空间适用场景
最低配置骁龙 6 系 / Helio P 系列4GB2GB+原版 MC 低画质
推荐配置骁龙 7 Gen 1 / 天玑 80006GB4GB+原版高画质 + 轻量模组
舒适配置骁龙 8 Gen 1 / 天玑 90008GB+8GB+大型整合包 + 光影

💡 上述表格仅为参考。若你的设备在运行 MC Java 版时出现卡顿，通常由多方面因素共同导致：

游戏内因素：渲染区块数量、画面设置、材质包、模组数量与兼容性、光影、实体数量

启动器侧因素：渲染器选择、Java 版本与运存分配、JVM 参数

设备侧因素：硬件性能、厂商云控策略、设备温度、后台进程数量

注意

即便达到"舒适配置"，在运行大型整合包（如 300+ 模组）时仍可能出现卡顿。

此时需要通过降低渲染区块、关闭光影、精简模组等方式进一步优化。

关于整合包与模组的兼容性

FCL 是在安卓端移植的 Java 版 MC 运行环境，通过转译层将 OpenGL/LWJGL 调用桥接到安卓的图形子系统。

由于这种移植性质，以下情况可能无法正常运行，属于运行环境的客观限制，而非启动器缺陷：

  • 依赖 PC 端外部程序的模组：少数 Mod（如 PythonMC、Minescript）需要 PC 端安装 Python 等运行时才能工作。这类 Mod 在安卓环境下缺少对应的外部运行时，因此无法正常运行。
  • PC 专属图形实现的模组：依赖完整 OpenGL 特性或特定 PC 渲染管线的模组，在转译层下可能无法完全模拟
  • 架构受限的原生库：模组内置的 native 库若无对应 ARM 架构版本，会导致加载失败
  • 过于庞大的整合包：对内存和 JVM 稳定性要求超出手机硬件承载能力的整合包

FCL 是开源社区项目，开发者在安卓的硬件限制下尽力复现了 Java 版的运行环境。遇到兼容性问题，欢迎通过 GitHub 理性反馈，便于开发者持续改进。
