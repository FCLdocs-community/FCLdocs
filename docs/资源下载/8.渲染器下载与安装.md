# 渲染器下载与安装

FCL 能在手机上跑 Minecraft Java 版，靠的是一个“翻译层”：Java 版发出的是桌面 OpenGL 指令，手机 GPU 只认 OpenGL ES 或 Vulkan，渲染器就在中间做转换。装错渲染器，或者渲染器和游戏版本对不上，最常见的表现就是进世界瞬间闪退、黑屏。

FCL 现在内置了 Krypton Wrapper、Holy-GL4ES、VGPU、Zink 和 MobileGlues。VirGL 在 2026.10 之后改成了 FCLRendererPlugin 插件；LTW 早期也内置过，后来改成了 APK 插件。列表里有想用的，直接选就行。Vulkan 是 26.2+ 的图形后端选项，不在渲染器列表里，别把它当成 OpenGL 渲染器。

## 该选哪个

名字看着多，其实先看游戏版本，再看手机 GPU，基本就能定下来。

### 看游戏版本

| 游戏版本 | 建议 |
| --- | --- |
| 26.x / 1.17 及以上 | MobileGlues（MG），或者默认的 Krypton Wrapper；光影、整合包优先 MG |
| 1.16.5 及更早 | VGPU 或 Holy-GL4ES，低配老机器优先这两个 |

官方 MG 插件 APK 要求游戏 1.17 及以上。FCL 内置的 MG 配合 SFPEW 兼容层没有这个限制，低版本也能先试，但能不能跑还得看实际效果。别把插件版的要求直接套到内置版上。

### 看手机和用途

- 主要玩光影、装整合包：优先 MG。Iris / OptiFine 光影，以及 Sodium、Create 这类模组的兼容工作，主要做在 MG 上。
- 骁龙（Adreno）想追帧数：MG 能正常玩之后，可以切 Zink 对比。Zink 走“桌面 GL → Vulkan”，一般要配合 Turnip 驱动；系统 Vulkan 驱动不一定更好，不同机型差别不小。
- 天玑 / Mali：MG 的兼容面更稳；遇到渲染异常，可以再开 ANGLE 模式试试。
- 低配老机器：能进游戏比什么都重要，VGPU 或 Holy 配低版本游戏仍然稳。
- LTW：早期内置，后来改成 APK 插件。现在很少作为首选；黑屏花屏时可以把 MG 和 LTW 换着试，特殊情况再拿出来用。

## 内置版和插件版

内置版不用额外装，打开 FCL 就能在渲染器列表里选。插件版要单独装 APK，装完 FCL 才能识别。VirGL、LTW、Freedreno 这些都在 FCLRendererPlugin 里。

后面的下载和安装主要讲插件。列表里没有的，再往下看。

## 从哪下载

### MobileGlues（MG）

MG 优先从 GitHub 拿，发布页是 [MobileGlues-release](https://github.com/MobileGL-Dev/MobileGlues-release/releases)。下载 `.apk`，别下成源码包。

FCL 本体可以从 [FCL 下载站](https://foldcraftlauncher.cn/html/down.html?id=0) 或 [柠枺资源站](https://miawa.cn/) 下载。MG 插件还是优先用官方 GitHub 发布页，别在网盘里随手拿。

### LTW、VirGL 和其他插件

在 FCL 的版本设置里，渲染器这一行右边有个下载图标。点开它会打开官方 [FCLRendererPlugin 发布页](https://github.com/ShirosakiMio/FCLRendererPlugin/releases/tag/Renderer) 和 [夸克网盘](https://pan.quark.cn/s/a9f6e9d860d9) 两个入口。LTW、VirGL 这类插件从那里装最省事。

Zink、Holy 现在 FCL 已经内置，不用再找第三方 APK；确实需要别的版本，再按发布页说明来。来源不明的包别装，渲染器 APK 进系统是有权限的。

## 装 MG 插件

### 装之前先确认

- 手机 GPU 支持 OpenGL ES 3.0 及以上，官方推荐 ES 3.2。近几年的手机基本都没问题；很老的机器就算装上了，也可能黑屏闪退。
- 游戏版本在 1.17 及以上。这是官方 MG 插件 APK 的要求；FCL 内置的 MG 配合 SFPEW 没有这个限制。
- FCL 能正常打开。MG 插件是给启动器用的，没有 FCL 装了也没用。

### 安装 APK

从上面的渠道下载 `.apk`，点开安装。系统可能会问“允许安装未知来源应用”，按提示同意就行，不同品牌的手机路径不太一样。

装好后桌面上会出现 MobileGlues 图标，点开就能改 MG 的设置。如果 FCL 已经内置 MG，就不用再装这个 APK；内置版没有独立图标，设置入口在渲染器列表的齿轮里。列表里同时出现内置版和插件版时，名字后缀不一样。

### 回到 FCL

装完打开 FCL。如果它还在后台，先清掉再开；也可以在渲染器列表里点一下刷新。FCL 重新扫描插件后，MG 就会出现在列表里。

## 在 FCL 里切到 MG

渲染器有两个地方能改：选中版本后，左边扳手「游戏设置」里的「渲染器」；还有「全局游戏设置」里的「渲染器」。

打开 FCL，选中版本，点左边扳手「游戏设置」，往下找到「渲染器」，点右边的齿轮。旁边那个下载图标是装插件用的，别点错。列表里认 MobileGlues 就行：内置版通常写 `MobileGlues (OpenGL 4.0)`，插件版会多一个 `1.17+` 之类的后缀。

### 单独给一个版本用 MG

想让某个版本单独用 MG，就在版本设置里打开「启用游戏特定设置」，再改「渲染器」。

没开这个开关的版本会跟着全局设置走。全局游戏设置里也能改渲染器，但只影响没开特定设置的版本；当前版本已经开了特定设置，再去改全局会提示不生效。

## 怎么确认 MG 在工作

切完进游戏看看。能稳定进世界，没有立刻闪退或黑屏，基本就对了。支持的环境里，MG 还会显示 GPU 占用百分比；能看到这个读数，说明它已经在工作。

如果还是黑屏或闪退，先别急着重装，换个渲染器试试：比如从 MG 切回内置的 Zink 或 Krypton Wrapper；FCL 里还有 VirGL，或者已经装了 VirGL 插件，也可以拿来对比。先看看问题出在渲染器，还是游戏和模组那边。

## 常见问题

### 换了渲染器，MG 的参数还在吗？

插件版在 MG App 里调过的设置（MultiDraw、ANGLE 等）只对 MG 生效，切走再切回来配置还在；内置版是在 FCL 渲染器齿轮里调，和插件版的配置分开。

### 黑屏、花屏、崩溃怎么办？

别一上来就重装。先换渲染器（MG 和 Zink / Krypton 对调），再试驱动或 MG 的 ANGLE 模式，然后看日志，最后再查模组和光影。渲染器原理可以看 [渲染器](/SuperDocs/手机启动器原理/渲染器)。

### APK 能从网盘随便下吗？

尽量走官方 GitHub 发布页。渲染器 APK 装进系统是有权限的，来源不明的包别装。官方发布页也写了用 `apksigner` 校验签名的方法，介意可以核对。
