# 渲染器下载与安装

FCL 能跑起来 Minecraft Java 版，核心靠的是一个“翻译层”：Java 版发出的是桌面 OpenGL 指令，手机 GPU 只认 OpenGL ES 或 Vulkan，渲染器就是夹在中间做转换的那一层。装错渲染器或版本不匹配，最常见的表现就是进世界瞬间闪退或黑屏。这篇只讲渲染器怎么选、从哪里下、怎么装、装完在 FCL 里怎么切过去。

---

## 先搞清楚你该装哪个

FCL 渲染器列表里名字很多。请你按游戏版本和设备两条线判断，基本能覆盖大多数情况。

**按游戏版本**

游戏版本 首选方案
1.17 及以上 MobileGlues（MG），光影和模组兼容性最好的一档
1.16.5 及更早 Holy GL4ES，老一代方案，低版本和低配机的兜底

社区多个教程明确提到 MobileGlues 在低版本上跑不了，硬装进去的典型症状就是闪退或黑屏。

- ***按设备与需求***

- 主力玩光影、装整合包：优先 MobileGlues。Iris / OptiFine 光影，以及 Sodium、Create 这类模组的兼容工作主要做在它上面。

- 骁龙（Adreno）设备想追帧数：MG 能正常玩之后，可以切 Zink 对比帧数。Zink 走的是“桌面 GL → Vulkan”路线，Vulkan 在 Adreno 上帧数上限通常更高，但不同机型实测差异方向不一定。

- 天玑 / Mali 设备：社区反馈里 MG 的兼容面更稳；渲染异常时可以再开 ANGLE 模式试。

- 低配老机器：能进游戏比什么都重要，Holy 配低版本游戏仍是稳妥组合。

 - LTW：另一种“桌面 GL → OpenGL ES”的实现，和 Holy 同期，社区里现在较少作为首选。部分教程会在黑屏花屏时建议“MG 或 LTW 换着试”，特殊情况下可以拿来尝试使用。

> ***FCL 本身还内置了 VirGL、Zink、Vulkan 等选项，不需要额外装 APK 就能在渲染器列表里直接选。下面讲的“下载与安装”，针对的是需要额外装 APK 插件才能出现在列表里的渲染器（主要是 MG、LTW、Holy 这一类）。***

### 额外apk插件的下载渠道

- MobileGlues（MG）——最推荐从 GitHub 拿

官方发布页（认准这个）：

```
https://github.com/MobileGL-Dev/MobileGlues-release/releases
```

当然我们也可以去FCL下载站或柠枺镜像站来进行

下载时请选 .apk 文件，以安装到手机上。

- LTW

LTW 的安装包通常通过社区网盘或 FCL 相关渠道分发，下载后直接安装即可。

- 其他渲染器

据我所知Zink、Holy 等也有第三方打包的 APK，但来源相对分散，下载时注意确认发布者可信度。如果不确定，先用 FCL 内置的 Zink / VirGL 测试，需要额外版本时再针对性找包。

#### 安装步骤（以 MG 为例）

- 第一步：确认三件事

*安装之前先过一遍，能省掉后面大半的排查时间：*

1. 手机 GPU 支持 OpenGL ES 3.0 以上。官方推荐 ES 3.2。近几年的手机基本都满足，很老的机器即使装了也可能黑屏闪退。
2. 游戏版本在 1.17 及以上。低于这个版本不要装 MG。
3. FCL 已经装好且能正常启动。MG 是给启动器用的插件，没有启动器它无处可用。

- 第二步：安装 APK

***从上面渠道下载 .apk 文件后，点击安装。系统会弹出“安装未知来源应用”的授权提示，按提示允许即可，不同品牌手机路径略有差异。***

安装成功的标志：桌面上出现 MobileGlues 的应用图标。apk安装之后你需要打开并配置你的mg设置。

- 第三步：打开FCL

直接打开FCL即可  但如果你从后台里有FCL，请清理后台，再重新打开。那么MG 就会出现在渲染器列表里了。

如何在 FCL 里切换到新渲染器？

1. 打开 FCL，选择你的游戏版本，然后进入左侧 「游戏设置」 （扳手图标那一个）。

2. 在设置列表里向下滑，找到 「渲染器」 一项，点击旁边的选择按钮。

3. 弹出的渲染器列表，MobileGlues 通常排在靠后的位置，继续下滑找到它（列表里显示的是全称 MobileGlues，不是缩写 MG）。

4. 点选即可
----
***改实例设置还是全局设置？ FCL 里有两个地方可以改渲染器：单个游戏实例的「游戏设置」，和启动器级的「全局游戏设置」。如果你打开了版本隔离，改实例那一层就够了；只有直接玩没有打开版本隔离的，才需要动全局。社区里的普遍建议是打开版本隔离，去改实例、少动全局，避免影响到其他实例。***

##### 切换后怎么确认真的生效？

- 切完渲染器，启动一个世界，看两个信号：

· 能稳定进入世界，没有立刻闪退或黑屏。这是最基本的判断。
· 在支持的环境下，MG 可以上报 GPU 占用百分比。进游戏后如果能看到这个读数，基本说明 MG 正在工作。

> ***如果切完仍然黑屏或闪退，先不要急着反复重装，优先换一个渲染器排除法验证（比如从 MG 切回内置的 VirGL 或 Zink），判断问题出在渲染器本身还是游戏/模组那边。***

###### 几个容易踩的坑

**① 换了渲染器，给MG调的参数还在吗？**

在 MG软件里调过的设置（MultiDraw、ANGLE 等）只对 MG 自己生效。切回 MG 时配置还在。

**② 黑屏 / 花屏 / 崩溃的排查顺序**

优先换渲染器！！一定要有耐心逐一排查问题！！

**③ 别从不明来源随手拿 APK**

> 渲染器 APK 装进系统后是有权限的。优先走官方 GitHub 发布页。
