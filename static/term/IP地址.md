# IP 地址

[brief]
IP 地址是设备在网络里的「门牌号」，用来让别人找到你。局域网 IP 通常是 `192.168.x.x`，公网 IP 则是对全网可见的地址。
[/brief]

[detail]
## IP 地址是什么

IP 地址（Internet Protocol Address）是网络中每台设备的唯一编号，类似现实中的门牌号。数据靠它找到目标设备。

## 两类 IP

- **局域网 IP（内网 IP）**：路由器分配给家里设备的地址，常见 `192.168.x.x`、`10.x.x.x`、`172.16~31.x.x`。只在本局域网内有效。
- **公网 IP（外网 IP）**：对互联网可见的地址，别人可以通过它找到你，但很多家庭宽带拿不到。

## 在联机中

- 同一局域网友机：填对方的**局域网 IP + 端口**。
- 异地联机：家用没公网 IP，通常要靠[内网穿透](window:/term/内网穿透)。

## 怎么查自己的 IP

- 局域网 IP：设置 → 关于手机 → 状态信息，或连的 Wi-Fi 详情里看。
- 公网 IP：用[浏览器](window:/term/浏览器)搜「IP」，或用内网穿透工具显示的地址。
[/detail]
