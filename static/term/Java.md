# Java

[brief]
Java 是一门编程语言，《我的世界》Java 版就是用 Java 写的。想在手机上运行 Java 版，必须先有一个能在安卓上跑的 Java 运行环境（FCL 已内置）。
[/brief]

[detail]
## Java 是什么

Java 是一门 1995 年发布的编程语言。「Minecraft Java 版」正是用 Java 编写，所以它不能直接跑在安卓上——安卓不认识标准的 Java 程序。

## 和 Minecraft 的关系

- 每个游戏版本对 **Java 大版本**有要求：老版本用 Java 8，新版本用 Java 17 / 21 / 25。
- 版本要求的 Java 不对，游戏就[崩溃](window:/term/崩溃)或打不开。
- FCL 内置了 Java 8 / 17 / 21 / 25，「自动选择」会按版本挑合适的。

## 新手要知道的

- 手机上**不需要自己去装 Java**，FCL 已经带好了。
- 别把电脑上的 Java 直接复制过来，架构不同、用不了。

:::tip
想看某个版本需要哪个 Java、为什么报 `UnsupportedClassVersionError`，见本站「Java虚拟机报错」。
:::
[/detail]
