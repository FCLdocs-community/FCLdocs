# Root

[brief]
Root 是获取安卓系统的最高管理员权限，能改系统文件、卸载预装应用等。Root 有风险，可能影响保修与安全，普通玩家玩 Minecraft 一般不需要。
[/brief]

[detail]
## 它是什么

Android 基于 Linux，Root 相当于拿到超级用户（root）权限，可以突破普通 App 的限制。

## 常见用途

- 修改系统文件、卸载预装应用；
- 使用需要高权限的工具。

## 风险

- 失去保修/影响系统更新；
- 安全风险增加；
- 操作不当可能变砖。

## 和 FCL 的关系

大部分功能不需要 Root。只有在访问受限目录、改系统文件等场景才可能涉及。
[/detail]
