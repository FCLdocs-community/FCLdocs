# VulkanMod

[brief]
VulkanMod 是一个把 Minecraft Java 版的图形接口从 OpenGL 替换成 Vulkan 的模组，用于降低 CPU 开销、提升性能，但兼容性有限。
[/brief]

[detail]
## 它做什么

VulkanMod 不是渲染优化插件，而是直接替换游戏的渲染后端，让 Minecraft 用 Vulkan 绘图。

## 特点

- 可能降低 CPU 开销、提升帧率；
- 与很多光影/模组不兼容；
- 属于实验性方案。

## 注意

它和 Minecraft 26.2 官方自带的 Vulkan 渲染后端不是一回事：VulkanMod 是第三方模组，官方后端是游戏内置的实验功能。
[/detail]
