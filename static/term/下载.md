# 下载

[brief]
下载就是把网上的文件「搬」到你的手机里。点网页或 App 里的「下载」按钮后，文件会先存到手机的「下载」文件夹。
[/brief]

[detail]
## 下载是什么

下载（Download）是把你手机之外（网络上）的文件复制到你手机里的过程。反过来，把手机里的文件传到网上叫「上传」。

## 下载后文件去哪了

- 一般会保存到手机的 **`Download`（下载）文件夹**，路径通常是 `/storage/emulated/0/Download/`。
- 下载完后，`.apk` 文件要点击安装；其他文件要按教程放到对应文件夹。

## 下载常见问题

- **速度慢或卡住**：换下载源、换网络，或用支持续传的下载工具。
- **没权限存不进去**：要给 App「存储权限」。
- **找不到下载的文件**：去「文件管理 → 下载」里找，或看浏览器/下载工具的「下载记录」。

:::tip
FCL 本身也内置了下载游戏、模组、整合包的功能，不一定要用浏览器。
:::
[/detail]
