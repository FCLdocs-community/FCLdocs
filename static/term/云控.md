# 云控

[brief]
云控是手机厂商通过联网远程控制你设备的一种机制，比如远程推更新、限速、改配置。它本身是中性技术，关键看厂商怎么用。
[/brief]

[detail]
## 云控是什么

云控（云端控制）指厂商在系统里预置一个常驻后台的服务，连到厂商服务器，接收并执行下发指令，例如「升级系统」「限制 CPU 频率」「推送广告」。

## 对游戏的影响

- 部分厂商的云控会在检测到游戏时**限制性能或帧率**，导致卡顿、锁帧。
- 有的会**杀后台**，影响下载或挂机。

## 应对

- 在系统设置里关闭该应用的「智能省电 / 后台限制」。
- 部分机型可卸载或停用云控服务（需 ADB，有风险，谨慎操作）。
- 尽量在厂商「游戏模式」或「性能模式」下运行。
[/detail]
