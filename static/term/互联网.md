# 互联网（Internet）

[brief]
互联网就是把全世界的电脑、手机、服务器用网络连起来的一个超级大网络。上网查资料、聊天、打游戏、下载，都是通过它完成的。
[/brief]

[detail]
## 互联网是什么

互联网（Internet）是"网络的网络"：无数个局域网、骨干网通过统一的通信协议（TCP/IP）互联，形成一个全球性的计算机网络。

## 关键概念

- **IP 地址**：每台联网设备的"门牌号"，用于定位。
- **域名与 DNS**：`baidu.com` 这样的名字，由 DNS 翻译成 IP 地址。
- **数据包**：信息被拆成小包，通过网络逐跳转发，到达目的地再重组。

## 和玩 Minecraft 的关系

- 下载版本、模组、光影都要通过互联网连接到对应服务器。
- 正版登录需要联网到 Mojang 的认证服务器。
- 联机游戏需要把游戏数据通过互联网实时传输。

:::note
"离线登录"里的"离线"指的是不连接 Mojang 的账号认证服务器，而不是完全不联网——下载资源、连接游戏服务器仍然需要互联网。
:::
[/detail]
