# 代理服务器（Proxy）

[brief]
代理服务器就是一台"中转站"电脑：你上网的请求先发到它那里，再由它转给真正的网站，把结果拿回来交给你。翻墙、加速、隐藏 IP 都靠它。
[/brief]

[detail]
## 代理的原理

正常情况下，你的手机/电脑直接连接目标网站：

```
你的设备 ────────────► 目标网站
```

使用代理后，数据多绕一个中间人：

```
你的设备 ──► 代理服务器 ──► 目标网站
```

这样目标网站看到的是代理服务器的 IP，而不是你的真实 IP。

## 主要用途

- **访问受限内容**：绕过地域限制或网络封锁（俗称"科学上网"）。
- **隐藏真实 IP**：保护隐私、降低被追踪风险。
- **加速访问**：代理节点可能走更优线路，改善延迟。
- **缓存与安全过滤**：企业、学校用它做统一上网管理和内容审计。

## 常见代理协议

- HTTP / HTTPS 代理：主要用于网页浏览。
- SOCKS5：更通用，可代理 TCP/UDP，游戏、下载也常用。
- VPN：广义上也是一种代理，但工作在网络层，会加密整台设备的流量。

:::
[/detail]
