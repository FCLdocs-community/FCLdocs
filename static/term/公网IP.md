# 公网 IP

[brief]
公网 IP 是对整个互联网可见的地址，别人能通过它找到你。家庭宽带通常拿不到公网 IP，所以异地联机常要借助内网穿透。
[/brief]

[detail]
## 公网 IP 是什么

公网 IP（外网 IP）是运营商分配、在整个互联网上唯一的地址。有了它，外网的人可以直接访问你的设备。

## 和内网 IP 的区别

- **内网 IP**：路由器分给设备的地址（如 `192.168.x.x`），只在本局域网有效。
- **公网 IP**：全网可见，别人能直连。

## 和联机的关系

- 有公网 IP：开好服务器后，别人填「你的公网 IP:端口」即可连入，速度快、延迟低。
- 没有公网 IP（大多数家宽）：用[内网穿透](window:/term/内网穿透)把内网服务转出去。

:::note
公网 IP 常是动态的（会变），且暴露到公网有安全风险，注意防护。
:::
[/detail]
