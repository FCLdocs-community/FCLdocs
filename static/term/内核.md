# 内核（Kernel）

[brief]
内核是操作系统的核心，负责管理 CPU、内存、硬件和系统调用。Android 的内核就是 Linux。
[/brief]

[detail]
## 它是什么

内核（Kernel）是操作系统最底层、权限最高的部分，负责：

- 调度 CPU；
- 管理内存；
- 驱动硬件；
- 提供系统调用。

## Android 与 Linux

Android 底层使用的就是 Linux 内核，但上层用户空间与桌面 Linux 不同（Bionic、ART 等）。

## 相关

- **用户空间**：普通程序运行的区域；
- **系统调用**：用户空间请求内核服务的接口。
[/detail]
