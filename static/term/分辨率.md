# 分辨率

[brief]
分辨率指画面有多少像素（如 720p、1080p）。分辨率越高画面越清晰，但越吃性能。手机玩 Java 版时常要适当降低分辨率来换流畅。
[/brief]

[detail]
## 分辨率是什么

分辨率（Resolution）指屏幕或画面横向 × 纵向的像素数，比如 `1920×1080`（常叫 1080p）、`1280×720`（720p）。像素越多，画面越精细，但 GPU 要画的点也越多。

## 和性能的关系

- 分辨率越高 → 显卡负担越大 → 帧率越低、越发热。
- 手机玩 Java 版时，适当**降低游戏分辨率**是常见的提帧手段。

## 常见问题

- 游戏画面被拉伸变形：多半是分辨率和屏幕比例不一致。
- 界面按钮跑到屏幕外：分辨率或全屏设置不对。

:::tip
想更流畅，优先降分辨率 + 降视距，比一味调设置有效。
:::
[/detail]
