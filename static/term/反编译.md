# 反编译（逆向工程）

[brief]
反编译就是"把已经编译好的程序，想办法还原成人类能看懂的形式"。破解软件、分析模组、汉化资源，都可能用到它。
[/brief]

[detail]
## 反编译是什么

程序写好源代码后，会被编译器翻译成机器码或字节码（编译），这个过程的逆向就是"反编译"（Decompile）。反编译把难懂的机器码尽量还原成可读的代码。

## 常见目标

- **Java 字节码**：`.class` / `.jar` 文件可以较容易地反编译成 Java 代码。
- **native 库**：`.so` / `.dll` 反编译成汇编/C 代码，难度大很多。

## 在 MC / FCL 场景中的用途

- 查看、修改模组的实现逻辑（汉化、改配方）。
- 分析游戏报错、定位问题。
- 提取资源文件（贴图、语言文件）。

:::warning 注意
反编译和修改他人作品可能涉及版权和许可问题，请尊重原作者的开源协议和授权。反编译用于学习、排障是合理用途，但不要用于盗版、破解付费内容等侵权行为。
:::
[/detail]
