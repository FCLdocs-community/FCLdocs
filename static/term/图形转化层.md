# 图形转化层（图形转译层）

[brief]
图形转化层是一个"翻译官"：它把电脑游戏发出的 OpenGL 画图指令，实时翻译成手机能听懂的 OpenGL ES 或 Vulkan 指令，这样手机才能显示电脑版 Minecraft 的画面。
[/brief]

[detail]
## 为什么要翻译

电脑版 Minecraft 使用桌面 OpenGL 画图，而手机只支持 OpenGL ES 或 Vulkan，两者接口不同。图形转化层就是夹在中间做实时翻译的中间层：

```
Minecraft (OpenGL) ──► 转化层 ──► 手机 GPU (OpenGL ES / Vulkan)
```

## 常见的转化层

- **GL4ES**：把 OpenGL 调用翻译成 OpenGL ES，是 1.16.5 及更早版本常用的后端。
- **ANGLE**：Google 开发，把 OpenGL ES 翻译成 Vulkan，可作为第二层翻译层使用。
- **VirGLRenderer**：把 OpenGL 翻译成 Vulkan 或 OpenGL ES，性能更好。
- **Zink**：基于 Vulkan 驱动实现 OpenGL。

## 代价

翻译不是免费的，它会带来额外的性能开销和延迟，某些图形效果也可能出现渲染错误（如水面变黑、天空花屏）。Minecraft 26.2 起原生支持 Vulkan，可消除这层翻译损耗，理论上性能更好。
[/detail]
