# 字节码（Bytecode）

[brief]
字节码是 Java 源代码编译后的"中间代码"，既不是人写的源码，也不是 CPU 能直接执行的机器码，需要由 JVM（或 ART）再翻译成机器码才能运行。
[/brief]

[detail]
## 在流程中的位置

```
Java 源码 (.java) → 编译 → 字节码 (.class/.jar) → JVM 翻译 → 机器码
```

## 为什么要分两步

字节码是跨平台的：同一份字节码，只要目标设备装了对应的 JVM，就能运行。这正是 Java"一次编写，到处运行"的基础。

## 常见文件

- `.class`：单个类的字节码；
- `.jar`：把很多 `.class` 和资源打包成一个文件，Minecraft 本体和模组都是 jar。

## 和 dex 的区别

Android 的 ART 只认 dex 字节码，标准 Java 字节码要先转换，这也是手机需要额外 JVM 的原因。
[/detail]
