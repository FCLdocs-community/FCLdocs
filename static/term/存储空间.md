# 存储空间

[brief]
存储空间就是手机长期存文件的地方（比如 128GB、256GB 那个）。装游戏、下模组、存存档都要占存储空间，空间不够会下载失败。
[/brief]

[detail]
## 存储空间是什么

存储空间（ROM / 内部存储）是设备**长期保存文件**的地方，照片、App、游戏都存在这里。它和[内存](window:/term/内存)不同：存储断电不丢，内存断电就清空。

## 在 FCL 中

- 游戏本体、模组、存档、整合包都占用存储空间。
- 大型整合包 + 光影可能占用数 GB。
- 空间不足时下载、解压、补全都会失败。

## 怎么清理

- 删除不玩的版本和整合包。
- 清理下载文件夹里用不上的文件。
- 用系统「存储」设置看谁占得多。

:::warning
给 FCL 和游戏预留足够空间（大型整合包建议至少 8GB 起），否则会出现「下载失败 / 无法解压」。
:::
[/detail]
