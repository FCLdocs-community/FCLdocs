# 安装包（APK）

[brief]
安装包就是用来安装 App 的文件，安卓上的安装包后缀是 `.apk`。FCL 下载下来的就是一个 apk，点它就能安装。
[/brief]

[detail]
## 安装包是什么

安装包是打包好的 App 安装文件。安卓系统的安装包后缀是 **`.apk`**，类似电脑上 Windows 的 `.exe`。

## 怎么安装 apk

1. 用浏览器或下载工具下载 `.apk` 文件。
2. 在「文件管理 → 下载」里找到它，点一下。
3. 系统可能提示「是否允许安装未知应用」，需要允许后继续。
4. 等进度走完，桌面上就会出现 App 图标。

## 常见问题

- **解析包错误 / 安装包损坏**：多半是下载不完整或文件坏了，重新下载。
- **无法安装**：可能是安卓版本太低（FCL 需要 Android 8 以上），或签名冲突（先卸载旧版）。
- **提示有风险**：正版 FCL 从官方渠道下载即可，注意别装到带捆绑的第三方包。

:::warning
只从官方或可信渠道下载安装包，第三方站点可能捆绑广告甚至恶意软件。
:::
[/detail]
