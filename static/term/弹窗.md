# 弹窗

[brief]
弹窗就是一个突然冒出来、盖在界面上的小窗口，一般要你点「确定 / 取消」之类的按钮才能继续。
[/brief]

[detail]
## 弹窗是什么

弹窗（对话框 / Dialog）是覆盖在当前界面之上的小窗口，用来提示信息、警告风险或让你做选择。例如「是否允许存储权限」「是否同意用户协议」。

## 在 FCL 中

- 首次启动会弹出**用户协议**和**权限**弹窗。
- 启动版本、安装模组时可能弹出**风险提示**。
- 出错时弹出**报错弹窗**。

## 注意

- 有些弹窗要点到「确定 / 关闭」才能消失，被挡住时往下滑或找按钮。
- 出现看不懂的弹窗，先读文字再决定，别急着乱点「确定」。

:::tip
只有按钮、看不到内容的弹窗，可能是显示不全或分辨率问题，可换竖屏 / 横屏或截图求助。
:::
[/detail]
