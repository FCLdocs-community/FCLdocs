# 文件夹 / 目录

[brief]
文件夹（也叫目录）就是用来装文件的「盒子」，可以一层套一层。手机上的「文件管理」就是用来查看文件夹的。
[/brief]

[detail]
## 文件夹 / 目录是什么

文件夹（Folder）是用来分类存放文件的容器，电脑上常叫「文件夹」，专业一点叫「目录（Directory）」。一个文件夹里可以再放别的文件夹（叫子文件夹），形成一层层的结构。

## 在 FCL 中常见的文件夹

- `.minecraft`：游戏主目录（前面有个点，表示隐藏）。
- `versions`：每个游戏版本一个子文件夹。
- `mods`：放[模组](window:/term/mod)的地方。
- `shaderpacks`：放[光影](window:/term/光影)包的地方。
- `saves`：放[存档](window:/term/存档)的地方。

## 怎么看手机里的文件夹

用「文件管理」或「MT 管理器」App，就能像看树一样一层层点进文件夹。FCL 也自带了文件管理功能。

:::note
安卓 11 以后，`Android/data` 这个文件夹在普通文件管理器里可能看不到，需要特殊工具，这属于系统限制，不是文件丢了。
:::
[/detail]
