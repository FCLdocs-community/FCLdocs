# 显卡（图形处理器）

[brief]
显卡就是电脑里负责"画图"的硬件，把图像和画面显示到屏幕上。玩游戏、看视频、跑光影都离不开它。
[/brief]

[detail]
## 显卡是什么

显卡（Graphics Card）负责把数据转换成图像并输出到屏幕。它核心是一颗 GPU（图形处理器）芯片，配合显存一起工作。

## 两类显卡

- **集成显卡（核显）**：GPU 集成在 CPU 里，共享系统内存，省电便宜，性能一般。
- **独立显卡（独显）**：独立板卡，带专用 GPU 和显存，性能强，适合游戏和渲染。

## 显卡和 GPU 的区别

- GPU 是"芯片"（图形处理器）。
- 显卡是"承载 GPU 的整块硬件"（含电路板、显存、散热、接口等）。
- 手机上没有独立显卡，GPU 直接集成在 SoC 芯片内。

## 和玩家的关系

- 电脑玩 Minecraft 加光影、高画质，主要看显卡性能。
- 手机 GPU 集成在 SoC 里，跑 Java 版光影压力大，是手机发热、掉帧的重要原因。
[/detail]
