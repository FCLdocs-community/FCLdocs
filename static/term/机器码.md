# 机器码（Machine Code）

[brief]
机器码是 CPU 能直接执行的二进制指令。源代码、字节码最终都要变成机器码才能跑起来，而且机器码和 CPU 架构绑定：x86 的机器码 ARM 芯片看不懂。
[/brief]

[detail]
## 它是什么

机器码是一串 0/1 指令，CPU 逐条执行。不同架构（x86、ARM）的指令集不同，机器码也互不通用。

## 在 Java 中的位置

Java 源码先编译成跨平台的字节码，再由 JVM 把字节码翻译成当前设备的机器码：

- 在电脑上，翻译成 x86 机器码；
- 在手机上，翻译成 ARM 机器码。

## 对玩家的意义

这也是为什么下载模组、整合包、启动器时要区分架构：装错架构的 native 库，机器码对不上，就会闪退或无法启动。
[/detail]
