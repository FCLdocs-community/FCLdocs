# 权限

[brief]
权限是 App 使用手机某项功能前，需要你同意的「许可」，比如读取文件、用相机、用麦克风。FCL 首次启动需要「存储权限」才能管游戏文件。
[/brief]

[detail]
## 权限是什么

权限（Permission）是安卓为了保护隐私和安全的机制：App 想用某项系统能力（读文件、联网、拍照、定位等），必须先获得你的授权。

## FCL 会用到的权限

- **存储权限（管理所有文件）**：FCL 的核心，用来读写游戏文件。首次启动会申请，务必允许。
- **麦克风**：仅游戏内语音类模组需要。
- **网络**：下载游戏、模组、登录账号必需。

## 怎么授权 / 改权限

- App 弹窗申请时点「允许」。
- 事后修改：设置 → 应用 → 找到该 App → 权限。
- 如果之前点了「不再询问」，需要去系统设置里手动改。

:::warning
如果拒绝「管理与所有文件的权限」，FCL 可能无法进入主界面或无法读写游戏文件。
:::
[/detail]
