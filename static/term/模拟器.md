# 模拟器（Emulator）

[brief]
模拟器就是用软件"假装"成另一台设备。电脑上的安卓模拟器能让你在电脑里跑手机 App，手机上的 Java 启动器则是在手机里跑电脑版 Minecraft。
[/brief]

[detail]
## 模拟器是什么

模拟器（Emulator）是让一个系统通过软件去模仿另一个系统的程序。它把目标系统的指令"翻译"成当前系统能执行的指令，从而运行原本不兼容的软件。

## 常见模拟器

- **安卓模拟器**：在电脑上模拟 Android，如 BlueStacks、雷电模拟器、MuMu。
- **游戏机模拟器**：在电脑/手机上模拟主机（如 PSP、Switch 模拟器）。
- **手机 Java 启动器**：在 Android 上运行 Java 版 Minecraft，本质上也是一种"Java 环境 + 图形转译"的模拟。

## 模拟和"移植"的区别

- **模拟**：通常指软件层面翻译执行，兼容性靠翻译层，性能有损耗。
- **移植**：把程序重新编译适配目标平台，原生运行，性能更好。

## 和玩家的关系

手机 Java 启动器（PojavLauncher 系）靠 JVM + LWJGL 移植 + 图形转化层，在 ARM 手机上运行 x86/Java 的 Minecraft，属于"移植 + 转译"结合的方案，因此性能损耗不可避免。
[/detail]
