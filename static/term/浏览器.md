# 浏览器

[brief]
浏览器就是用来上网看网页、下载东西的 App，比如 Chrome、Edge、夸克、UC、系统自带的「浏览器」。手机上一般在桌面能找到一个彩色圆球的图标。
[/brief]

[detail]
## 浏览器是什么

浏览器（Browser）是专门用来打开网页的程序。你在地址栏输入网址，它就把对应的网页显示出来。下载软件、查资料、看教程，基本都要用到它。

## 常见的浏览器

- **手机自带**：大部分安卓手机出厂就装了一个浏览器（有时叫「浏览器」「网页」或厂商名字）。
- **第三方**：Chrome、Edge、Firefox、夸克、UC、QQ 浏览器、Via 等。

## 在下载 FCL 时的作用

- 访问官网或下载站、点「下载」按钮，都用浏览器完成。
- 下载下来的通常是 `.apk` 安装包，再到「文件管理」里点它安装。
- 如果打不开某些网址，可能需要开[代理](window:/term/代理服务器)或换网络。

:::tip
手机上如果找不到浏览器，可以在「应用商店」里搜索安装一个，或者用 QQ / 微信自带的浏览器打开链接。
:::
[/detail]
