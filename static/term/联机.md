# 联机

[brief]
联机就是和其他玩家一起玩同一个世界。常见方式有：同一局域网、内网穿透/组网、进别人的服务器。
[/brief]

[detail]
## 联机是什么

联机（多人游戏）指多个玩家在同一个世界里一起玩。

## 常见联机方式

- **局域网联机**：在同一个 Wi-Fi 下，一个人「对局域网开放」，别人在多人列表里加入。
- **内网穿透 / 组网**：不在同一网络时，借助工具把内网服务转出去，或组成虚拟局域网。
- **进服务器**：直接连接别人搭好的[服务器](window:/term/服务器)。

## 注意

- 想进**正版验证**的服务器，需要[正版](window:/term/正版)账号；离线服随便进。
- 联机时所有玩家的**游戏版本和模组要基本一致**，否则连不上或崩溃。

:::tip
同 Wi-Fi 最省事；异地联机优先看本站「联机途径」章节。
:::
[/detail]
