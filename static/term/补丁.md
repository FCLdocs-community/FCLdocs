# 补丁（Patch）

[brief]
补丁就是"修复包"，用来给系统或软件打上修复漏洞、解决 bug 的小更新。手机系统推送的小更新、游戏的 bug 修复都属于补丁。
[/brief]

[detail]
## 补丁是什么

补丁（Patch）是对软件的小范围修改，用于修复漏洞、bug，或小幅调整功能，而不需要发布完整新版本。

## 常见类型

- **安全补丁**：修复安全漏洞，Android 每月都有安全补丁。
- **Bug 修复补丁**：解决已知问题。
- **功能补丁**：小幅新增或调整功能。

## 在手机中的体现

手机厂商会定期推送"系统补丁"（如 Android 安全更新），修复系统漏洞、改善稳定性。厂商云控也可能通过推送补丁来远程修复某些问题。

:::tip
及时安装安全补丁有助于保护设备安全，但安装前请确认来源可靠，避免安装来路不明的"补丁包"。
:::
[/detail]
