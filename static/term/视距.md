# 视距

[brief]
视距指你能看到多远的方块范围，单位是区块。视距越大看得越远，但越吃性能。手机玩 Java 版建议调小（如 6~8 区块）。
[/brief]

[detail]
## 视距是什么

视距（Render Distance）指游戏渲染显示的范围，以[区块](window:/term/MC区块)为单位。视距 8 就代表以你为中心，显示半径 8 个区块内的世界。

## 和性能的关系

视距是最影响性能的设置之一：

- 视距翻倍，需要渲染的区块数量约变成**四倍**。
- 视距越大，越吃 CPU、GPU 和内存。

## 建议

- 手机玩 Java 版：**6~8 区块**通常比较合适。
- 卡顿就先降视距，再考虑降画质。

:::tip
视距调太高，除了卡，还会让「加载区块」变慢、落地时看到地形「长出来」。
:::
[/detail]
