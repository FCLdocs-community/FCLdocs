# 资源包（材质包）

[brief]
资源包（又叫材质包）用来更换游戏里的贴图、音效、字体等外观，放进 `resourcepacks` 文件夹，再在游戏里启用即可。
[/brief]

[detail]
## 资源包是什么

资源包（Resource Pack），在手机玩家口中常叫「材质包」，用来替换游戏里的**贴图、模型、音效、字体、语言**等资源，从而改变画面外观。

## 怎么用

1. 下载资源包（通常是 `.zip`，**不要解压**）。
2. 放进游戏目录的 `resourcepacks` 文件夹，或在 FCL 的资源包管理里导入。
3. 进入游戏 → 选项 → 资源包，把它移到右侧「已启用」。

## 注意

- 资源包**不能加新玩法**，只能改外观；要加内容用[模组](window:/term/mod)。
- 高清材质包（如 256x、512x）会明显增加显存和性能负担，手机可能吃不消。

:::tip
资源包和[光影](window:/term/光影)是两回事：资源包改贴图，光影改光照渲染。
:::
[/detail]
