# 路径

[brief]
路径就是文件或文件夹的「完整地址」，告诉你它具体在哪。比如 `/storage/emulated/0/FCL/.minecraft/` 就是一个路径。
[/brief]

[detail]
## 路径是什么

路径（Path）是文件或文件夹在整个存储里的「门牌号」，由一连串用斜杠 `/` 隔开的文件夹名组成，从最外层一直写到目标。

例如：

```
/storage/emulated/0/FCL/.minecraft/versions/1.20.1/mods
```

读法是从左到右一层层往里走：先到存储根目录，进 `FCL`，进 `.minecraft`，进 `versions`，进某个版本，最后进 `mods`。

## 常见路径

- `/storage/emulated/0/`：手机内部存储的根目录，通常也叫「内部存储」。
- `/storage/emulated/0/Download/`：系统下载文件夹。
- `/storage/emulated/0/FCL/`：FCL 的共享目录。

:::tip
路径里的斜杠一定是**正斜杠 `/`**（英文），不是「\」。复制路径时注意别多复制了空格。
:::
[/detail]
