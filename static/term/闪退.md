# 闪退

[brief]
闪退就是 App 或游戏「突然自己关掉」，没有报错界面，直接回到桌面。闪退的原因很多，通常要先看[日志](window:/term/日志)才能确定。
[/brief]

[detail]
## 闪退是什么

闪退（Crash / 崩溃退出）指程序在运行中突然关闭、回到手机桌面。它和「有报错弹窗的崩溃」不同——闪退往往什么提示都没有。

## 常见原因

- **内存不足**：分配的内存太小或设备剩余内存不够，进程被系统杀掉。
- **Java / 版本不匹配**：游戏需要的 Java 版本和当前选的不一致。
- **渲染器 / 驱动问题**：图形环境没准备好。
- **模组冲突或缺少前置**：装了不兼容或缺依赖的模组。
- **文件损坏**：下载不完整的版本、模组或资源文件。

## 怎么办

1. 先想办法拿到[日志](window:/term/日志)（游戏日志或启动器日志）。
2. 对照本站「报错解决」章节逐项排查。
3. 回忆是「刚改了什么设置 / 装了什么模组」之后才闪退的，优先回退那一步。
[/detail]
