# ARM 与 x86 架构

[brief]
ARM 和 x86 是两种"芯片能听懂的语言"（指令集架构）。手机、平板基本用 ARM（省电），电脑基本用 x86（性能强）。两种架构的程序互不通用。
[/brief]

[detail]
## 什么是指令集架构

CPU 不认识高级语言，它只执行最底层的机器指令。不同的 CPU 设计规定了不同的指令集，就像不同国家的人说不同的语言。

- **x86**：由 Intel、AMD 主导，历史悠久，性能强、功耗高，统治桌面和服务器。
- **ARM**：由英国 ARM 公司授权设计，功耗低、发热小，统治手机、平板、嵌入式设备。苹果 M 系列芯片也是 ARM。

## 为什么架构不同会导致不兼容

程序编译后是特定架构的机器码：

- 为 x86 编译的 `.exe`、`.dll`、`.so`，ARM 芯片"看不懂"，反之亦然。
- 这正是 Minecraft Java 版（x86 环境）无法直接在手机（ARM）运行的原因之一，需要靠 JVM + 转译层来"翻译"。

## 两者的现状

- 手机、平板、Mac（近年）：ARM。
- 传统 Windows PC、服务器：x86（含 x64）。
- 趋势：ARM 凭借能效优势，正在向笔记本、服务器渗透；x86 仍占据高性能桌面和游戏市场。

## 对玩家的意义

下载软件、模组、整合包时要注意区分架构版本。比如 FCL 的安装包、native 库、`.so` 文件都有 arm64 / x86 之分，选错版本会无法运行或闪退。
[/detail]
