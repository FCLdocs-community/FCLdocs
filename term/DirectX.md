# DirectX（Direct3D）

[brief]
DirectX 是微软的图形与多媒体接口集合，其中画图的叫 Direct3D。它主要用于 Windows 和 Xbox，是 Windows 游戏的主流图形接口。
[/brief]

[detail]
## 它是什么

DirectX 是微软推出的一整套 API，包含图形（Direct3D）、声音（DirectSound/XAudio2）、输入（DirectInput）等。日常说"游戏用 DirectX"通常指 Direct3D。

## 版本

- DirectX 9/10/11：经典版本；
- **DirectX 12**：2015 年推出，底层、贴近硬件，类似 Vulkan。

## 平台

仅 Windows、Xbox。想在 Linux/macOS 上跑，需要 Wine + DXVK 等转换层。
[/detail]
