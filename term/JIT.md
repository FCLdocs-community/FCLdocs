# JIT（即时编译）

[brief]
JIT（Just-In-Time）是 JVM 在运行时把"热点"字节码即时编译成机器码的技术。它让 Java 程序越跑越快，但也需要预热时间。
[/brief]

[detail]
## 它解决什么问题

如果 JVM 逐条解释字节码，速度会很慢。JIT 会找出反复执行的代码，把它编译成机器码缓存起来，之后直接执行机器码。

## 特点

- 启动时偏慢（要预热）；
- 运行一段时间后速度明显提升；
- 和"AOT 提前编译"相对。

## 对玩家的意义

- 刚进游戏时的卡顿，部分来自 JIT 预热；
- 长时间游玩后帧率往往会更稳定一些。
[/detail]
