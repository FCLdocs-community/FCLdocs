# RenderDragon

[brief]
RenderDragon 是 Minecraft 基岩版使用的渲染引擎，原生支持 Vulkan、DirectX 12 等现代图形接口，并内置光追。它和 Java 版的 Blaze3D 是两套完全不同的东西。
[/brief]

[detail]
## 它是什么

RenderDragon 是基岩版（Bedrock）的渲染引擎，2019 年前后逐步替换旧引擎。

## 特点

- 原生支持现代图形 API（Vulkan、DirectX 12、Metal）；
- 内置光线追踪能力；
- 光影生态与 Java 版不通用。

## 容易混淆的点

基岩版不是"Java 版换了个引擎"。它是另一套用 C++ 写的游戏，模组、光影、存档格式都与 Java 版不同。
[/detail]
