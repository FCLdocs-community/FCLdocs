# SQLite 数据库

[brief]
SQLite 是一种"轻量级数据库"，它把数据存成一个小文件，很多手机 App（包括 Minecraft）都用它来保存游戏存档、设置等数据。
[/brief]

[detail]
## SQLite 是什么

SQLite 是一个嵌入式关系型数据库。它最大的特点是不需要单独的数据库服务器——整个数据库就是一个文件，程序直接读写这个文件即可。

## 特点

- **轻量**：单文件，无需安装配置。
- **零服务器**：内嵌在应用程序里。
- **广泛使用**：手机 App、桌面软件、浏览器都大量采用。

## 在 Minecraft 中的使用

- 存档里的部分数据（如方块、实体信息）以数据库形式组织。
- 某些启动器用 SQLite 保存账号信息、版本配置、日志等。
- 用 MT 管理器查看 `.db` 文件时，看到的就是 SQLite 数据库的内容。

:::note
不要随意修改游戏或启动器的数据库文件，损坏后可能导致存档丢失或启动器异常。
:::
[/detail]
