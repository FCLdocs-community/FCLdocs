# UI（用户界面）

[brief]
UI 就是你看到的 App 界面：按钮、图标、菜单、布局这些。UI 设计得好不好，直接决定一个 App 用起来顺不顺手。
[/brief]

[detail]
## UI 是什么

UI（User Interface，用户界面）是人机交互的"门面"。用户通过界面上的按钮、输入框、图标、菜单来操作软件，软件也通过界面把信息反馈给用户。

## 相关概念

- **GUI**：图形用户界面，用图形元素（而非命令行）操作，绝大多数 App 都是 GUI。
- **UX**：用户体验，比 UI 更广，关注使用是否顺畅、逻辑是否合理。
- **UI 设计**：决定配色、字体、图标、布局的美观与易用性。

## 在 FCL 中的体现

FCL 启动器有主界面、版本管理页、下载页、设置页等多个 UI 页面。不同启动器（FCL、Zalith 等）的 UI 设计各异，这也是玩家选择启动器时考虑的因素之一。UI 清晰好用，能降低新手上手难度。
[/detail]
