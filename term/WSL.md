# WSL（Windows Subsystem for Linux）

[brief]
WSL 是 Windows 自带的一个功能，让你能在 Windows 里直接运行 Linux 环境，不用装虚拟机。适合开发者和喜欢折腾的用户。
[/brief]

[detail]
## WSL 是什么

WSL（Windows Subsystem for Linux，适用于 Linux 的 Windows 子系统）允许在 Windows 上原生运行 Linux 发行版（如 Ubuntu），无需虚拟机或双系统。

## 版本

- **WSL 1**：通过兼容层翻译 Linux 系统调用。
- **WSL 2**：基于轻量虚拟机，含真正的 Linux 内核，兼容性和性能更好。

## 用途

- 运行 Linux 命令行工具、开发环境。
- 编译、测试需要 Linux 的程序。
- 与 Windows 文件互相访问。

## 和玩家的关系

在讲解"如何在 Windows 上运行 Linux 程序"时，WSL 是一种方案。与安卓模拟器、虚拟机类似，它让一个系统能运行另一个系统的程序，是"跨系统运行"的典型工具之一。
[/detail]
