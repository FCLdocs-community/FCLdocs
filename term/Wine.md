# Wine

[brief]
Wine 是让 Windows 程序在 Linux/macOS 上运行的兼容层。它把 Windows 的系统调用翻译成当前系统的调用，而不是模拟一整台电脑。
[/brief]

[detail]
## 它是什么

Wine（Wine Is Not an Emulator）是一个兼容层，让 Windows 的 `.exe` 能在非 Windows 系统上运行。

## 常见相关

- **Proton**：Valve 基于 Wine 的游戏兼容方案；
- **DXVK**：把 DirectX 调用转换为 Vulkan 的组件，常与 Wine 搭配。

## 和手机启动器的区别

手机跑 Minecraft Java 版用的是"JVM + LWJGL 移植"，不是 Wine。看到 Wine 多在电脑 Linux/Steam Deck 场景。
[/detail]
