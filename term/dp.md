# dp（密度无关像素）

[brief]
dp（density-independent pixel，密度无关像素）是 Android 的尺寸单位，会随屏幕密度自动换算成像素，让同一个控件在不同手机上看起来大小接近。
[/brief]

[detail]
## dp 是什么

dp（density-independent pixel，密度无关像素），也叫 dip，是 Android 用来描述界面尺寸的单位。它按屏幕密度换算成实际像素：密度越高，1 dp 对应的物理像素越多，但视觉大小基本一致。

以 160 dpi 为基准，大致换算关系如下：

| 屏幕密度 | 1 dp 约等于 |
|---|---|
| 160 dpi（mdpi） | 1 px |
| 320 dpi（xhdpi） | 2 px |
| 480 dpi（xxhdpi） | 3 px |

## 在 FCL 布局中的用法

FCL 按键的坐标用相对屏幕的百分比表示，尺寸则既可以用百分比，也可以用 dp：

- **百分比**：随屏幕大小缩放，适合希望占屏比例固定的控件。
- **dp**：随屏幕密度缩放，视觉大小稳定，适合按钮、边框、圆角这类需要固定手感的元素。

所以同一个用 dp 设定的按键，在低密度和高密度手机上「看起来」差不多大。

:::tip
和 dp 经常一起出现的还有 sp，专门用于字体大小，会额外跟随系统字号设置。FCL 按键样式里的文本大小用的就是 sp。
:::
[/detail]
