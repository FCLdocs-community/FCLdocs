# 二进制（Binary）

[brief]
二进制是计算机最底层的语言，只用 0 和 1 两个数字表示一切数据。你手机里的照片、游戏、音乐，本质上都是一长串 0 和 1。
[/brief]

[detail]
## 二进制是什么

二进制是"逢二进一"的计数系统，只有 0 和 1。计算机用高低电平（通电/断电）来表示 0 和 1，所以所有数据最终都以二进制形式存储和处理。

## 为什么计算机用二进制

- 电子电路最容易稳定地区分"开/关"两种状态。
- 逻辑运算（与、或、非）天然对应二进制。
- 其他进制（八进制、十六进制）都可以很方便地和二进制转换。

## 和玩家的关系

- 文件底层都是二进制，十六进制编辑器显示的正是二进制数据的分组表示。
- "二进制文件"（`.so`、`.dll`、`.exe`、`.jar`）指编译后无法直接阅读、只能被机器执行的程序文件，区别于可读的文本文件。
[/detail]
