# 交叉编译（Cross Compile）

[brief]
交叉编译是"在一种设备上，为另一种设备编译程序"。比如在电脑上编译出能在 ARM 手机运行的 `.so`，就是交叉编译。
[/brief]

[detail]
## 为什么需要它

手机性能、系统都有限，不可能直接在手机上编译大型项目。于是先在电脑上编译好，再打包给手机用。

## 做交叉编译要什么

- 目标平台的编译器/工具链（Android 用 NDK）；
- 目标 CPU 架构（arm、arm64、x86、x86_64）；
- 目标系统的库（Android 用 Bionic）。

## 在 FCL 里的体现

FCL 内置的每个 Java 运行时都按架构分包（bin-arm、bin-arm64 等），这些就是交叉编译的产物。
[/detail]
