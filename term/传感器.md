# 传感器（Sensor / CMOS）

[brief]
传感器是手机里"感知外界"的元件，比如摄像头里的 CMOS 负责感光成像，还有加速度计、陀螺仪、光线传感器等。
[/brief]

[detail]
## 传感器是什么

传感器（Sensor）能把外界的物理量（光、声音、运动、温度等）转换成电信号，让设备"感知"环境。

## 手机常见的传感器

| 传感器 | 作用 |
|--------|------|
| CMOS 图像传感器 | 摄像头感光成像 |
| 加速度计 / 陀螺仪 | 检测运动、旋转、方向 |
| 光线传感器 | 自动调节屏幕亮度 |
| 距离传感器 | 打电话时熄屏 |
| 指纹/3D 结构光 | 生物识别解锁 |

## CMOS 是什么

CMOS（互补金属氧化物半导体）是一种制造工艺，也被用来泛指采用该工艺的图像传感器。手机、相机的摄像头感光元件基本都是 CMOS。它的好坏直接决定拍照质量。

## 和玩家的关系

摄像头素质、光线传感器等虽与游戏性能无直接关系，但都是手机体验的一部分。挑手机时"相机配置"主要看 CMOS 型号、像素和算法。
[/detail]
