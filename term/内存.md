# 内存（运行内存）

[brief]
内存（运行内存 / RAM / 运存）是手机临时存放正在运行的程序数据的地方。内存越大，能同时跑的东西越多。游戏卡顿、闪退常和内存有关。
[/brief]

[detail]
## 内存是什么

内存（RAM，也叫运行内存、运存）是设备用来临时存放「正在运行的程序和数据」的部件。它读写很快，但断电就清空，和设备长期存文件的「存储空间」不是一回事。

## 内存和存储别混

| | 内存（运存 / RAM） | 存储空间（ROM） |
|---|---|---|
| 用途 | 运行程序 | 长期存文件 |
| 特点 | 断电清空 | 断电保留 |
| 单位感受 | 8GB / 12GB 够用 | 128GB / 256GB 越大越好 |

## 和游戏的关系

- 游戏要启动就得占内存，给太少会崩，给太多系统会被挤爆。
- FCL 的「游戏内存」指的是**分配给游戏的 Java 堆内存**，不是手机总内存。
- 手机剩余内存不足时，系统可能杀掉后台甚至游戏进程 → [闪退](window:/term/闪退)。

:::tip
分配游戏内存时，通常给系统留 2GB 以上余量，不要一股脑拉满。
:::
[/detail]
