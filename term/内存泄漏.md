# 内存泄漏（Memory Leak）

[brief]
内存泄漏就是程序"占用了内存却忘了还"。占得越多、越久不还，可用内存就越少，最终导致游戏越来越卡，甚至崩溃。
[/brief]

[detail]
## 内存泄漏是怎么发生的

程序运行时会向系统申请内存来存数据，用完应该释放。如果程序因为代码缺陷，申请了内存却没有释放，这部分内存就再也回不来了，这就是"泄漏"。

## 危害

- 内存占用持续上涨，可用内存越来越少。
- 系统被迫频繁回收，导致卡顿。
- 严重时内存耗尽，程序崩溃（OutOfMemoryError）。

## 在 Minecraft 中的表现

- 玩久了帧数逐渐下降，越来越卡。
- 长时间挂机后内存占用异常升高。
- 最终弹出内存不足错误或直接闪退。

## 和 Java 的关系

Java 有垃圾回收（GC）机制，理论上会自动回收不再使用的内存，减少泄漏。但如果代码持有不该持有的引用（如缓存不清理、监听器不注销），GC 也无法回收，仍会发生泄漏。这也是为什么 MC 加大量模组后容易出现内存问题。
[/detail]
