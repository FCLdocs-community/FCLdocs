# 压缩包 / 解压

[brief]
压缩包是把很多文件「打包并压小」成一个文件（常见后缀 `.zip`、`.rar`、`.7z`）。解压就是把压缩包还原回一堆文件的操作，手机常用「MT 管理器」来解压。
[/brief]

[detail]
## 压缩包是什么

压缩包是把一个或多个文件合并、压缩成单个文件，方便传输和存储。常见的压缩格式有 `.zip`、`.rar`、`.7z`、`.tar.gz` 等。

## 解压是什么

解压（解压缩）就是把压缩包「还原」成里面的原始文件。

- **安装模组时**：模组是 `.jar` 文件，**不要解压**，直接放进 `mods` 文件夹即可。
- **安装存档 / 整合包时**：拿到的是压缩包，需要解压，再把里面的内容放到正确位置。
- **光影包**：一般是 `.zip`，**不要解压**，直接扔进 `shaderpacks` 文件夹。

## 手机上怎么解压

- 用 **MT 管理器**（推荐）、ES 文件浏览器等文件管理 App，长按压缩包选「解压」。
- 系统自带「文件管理」有些也支持解压。

:::tip
关键区别：**有的东西要解压（存档、整合包），有的东西一定不能解压（模组、光影包）**。不确定时先查教程，解压错了游戏就加载不了。
:::
[/detail]
