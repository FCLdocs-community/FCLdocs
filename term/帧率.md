# 帧率（FPS）

[brief]
帧率（FPS）指每秒画多少张画面。数值越高越流畅，60 帧就够顺，30 帧勉强，低于 20 帧明显卡。手机玩 Java 版帧率受硬件和设置影响很大。
[/brief]

[detail]
## 帧率是什么

帧率（Frame Rate，单位 FPS，Frames Per Second）表示每秒钟画面刷新多少次。

- **60 FPS**：流畅，大多数人的舒适线。
- **30 FPS**：能玩，略顿。
- **< 20 FPS**：明显卡顿。

## 影响帧率的因素

- 硬件性能（CPU / GPU）
- 视距、分辨率、画质、光影
- 模组数量、设备发热降频

## 怎么提帧

- 降低视距和分辨率。
- 关闭光影或换轻量光影。
- 装优化模组（如 Sodium）。
- 给系统留足内存，避免过热降频。

:::note
帧率是「波动」的：复杂场景（大量方块、生物、光影）会明显掉帧，稳定 60 比峰值 200 更重要。
:::
[/detail]
