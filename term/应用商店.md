# 应用商店

[brief]
应用商店是手机里下载安装 App 的官方「商店」，比如华为应用市场、小米应用商店、OPPO 软件商店。打开它搜名字就能装软件。
[/brief]

[detail]
## 应用商店是什么

应用商店（App Store / 应用市场）是手机厂商或第三方提供的 App 下载平台，里面有大量 App，点「安装」即可自动下载并装好，比手动下载 apk 更省事。

## 常见应用商店

- 手机自带：华为应用市场、小米应用商店、vivo 应用商店、OPPO 软件商店、荣耀应用市场等。
- 第三方：酷安、应用宝、TapTap 等。

## 和 FCL 的关系

- FCL 有时能在应用商店里搜到，但**更推荐去官网或 GitHub 下载最新版**，商店里的版本可能很旧。
- 从商店安装的版本通常能自动更新，但从官网下载的需要自己手动更新。
[/detail]
