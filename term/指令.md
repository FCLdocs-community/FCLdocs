# 指令（命令）

[brief]
指令是游戏里用输入框敲的一串特殊命令，以斜杠 `/` 开头，比如 `/gamemode creative`。它和「启动器设置」不是一个地方。
[/brief]

[detail]
## 指令是什么

指令（Command，也叫命令）是 Minecraft 里在**聊天输入框**里输入、以 `/` 开头的一行文字，用来执行特殊操作，例如：

- `/gamemode creative`：切换创造模式。
- `/time set day`：设置白天。
- `/tp`：传送。

## 在哪输入

在游戏内打开聊天（默认按 `T` 或 `/`），输入后回车执行。

## 新手常见误区

- 把「死亡不掉落」「开麦」「切换模式」当成**启动器设置**去找——这些其实是**游戏内**的事（指令或游戏设置）。
- 服务器里很多指令需要管理员权限（OP），普通玩家用不了。

:::note
`/gamerule keepInventory true` 就是常说的「死亡不掉落」。
:::
[/detail]
