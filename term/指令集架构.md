# 指令集架构（ISA）

[brief]
指令集架构（ISA）是 CPU 能理解的"指令清单"，决定了机器码长什么样。常见的两大阵营是电脑的 x86 和手机的 ARM，两者的机器码互不通用。
[/brief]

[detail]
## 它是什么

ISA（Instruction Set Architecture）规定了一颗 CPU 支持哪些指令、寄存器怎么用。程序员编译出的机器码必须符合目标 CPU 的 ISA。

## 常见 ISA

- **x86 / x86_64**：Intel、AMD，主导电脑；
- **ARM**：手机、平板、苹果 M 系列；
- **RISC-V**：新兴开源架构。

## 对玩家的意义

下载启动器、native 库、整合包时要选对架构（arm64 最常见），否则机器码对不上会闪退。

## 相关

- **机器码**：ISA 的具体指令；
- **ARM 与 x86 架构**：更通俗的对比。
[/detail]
