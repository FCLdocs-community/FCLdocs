# 数据包

[brief]
数据包是放在世界存档里的「规则包」，能改合成配方、进度、维度、结构等游戏机制，和改外观的资源包不同。
[/brief]

[detail]
## 数据包是什么

数据包（Data Pack）是一组用 JSON / 函数写成的规则文件，放在存档的 `datapacks` 文件夹里，用来修改**游戏机制**：合成配方、成就进度、战利品表、自定义维度、结构生成等。

## 和资源包、模组的区别

- **数据包**：改游戏规则，放在存档里，服务器也能用，不用装模组加载器。
- **资源包**：改外观贴图 / 音效。
- **[模组](window:/term/mod)**：改代码、加内容，需要 Mod 加载器。

## 怎么用

放进存档的 `datapacks` 文件夹，或在 FCL 的「世界/数据包」里管理。若数据包有语法错误，进入世界时会提示「安全错误」，需要修复或移除。
[/detail]
