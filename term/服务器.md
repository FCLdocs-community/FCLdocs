# 服务器（Server）

[brief]
服务器就是一台"24 小时不关机、专门给别人提供服务"的电脑。你逛的网站、玩的游戏联机、用的网盘，背后都有一台或多台服务器在默默干活。
[/brief]

[detail]
## 服务器是什么？

服务器本质上也是一台电脑，但它和普通家用电脑有三点不同：

- **持续在线**：服务器 7×24 小时运行，几乎不关机，否则服务就会中断。
- **职责单一**：一台服务器往往只专注做一件事，比如存文件、跑网站、当游戏服务端。
- **性能与稳定优先**：CPU、内存、硬盘、网络都往"扛得住高并发、不容易崩"的方向配。

## 常见类型

| 类型 | 用途 |
|------|------|
| 网站服务器 | 托管网站页面，你打开网址看到的内容就存在它上面 |
| 游戏服务器 | 运行 Minecraft 等游戏的多人服务端 |
| 文件/云盘服务器 | 存储和分发文件 |
| 数据库服务器 | 存放和管理数据 |

## 手机云控里的"服务器"

厂商在云端部署服务器，用来给手机推送更新、下发指令、收集诊断信息，这就是所谓"云控"。这类服务器属于厂商控制，用户无法直接接触。
[/detail]
