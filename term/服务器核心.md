# 服务器核心（Server Core）

[brief]
服务器核心就是运行 Minecraft 服务器的程序，通常是一个用 Java 运行的 .jar 文件。不同核心决定服务器支持插件、模组，还是两者兼有。
[/brief]

[detail]
## 服务器核心是什么

服务器核心（Server Core）是真正在后台运行 Minecraft 世界、处理玩家连接与游戏逻辑的程序。下载对应的 `.jar`，用 Java 启动，它就是一个 Minecraft 服务器，其他玩家可以连进来一起玩。

## 常见类型

- **原版核心**：Mojang 官方 Vanilla，最干净，但不支持插件和模组。
- **插件核心**：如 Spigot、Paper、Purpur，通过插件扩展功能，玩家客户端无需安装任何东西。
- **模组核心**：如 Forge、NeoForge、Fabric，服务端和客户端都要装相同的模组。
- **混合核心**：同时支持插件与模组，稳定性通常较差。
- **代理端**：如 Velocity，本身不加载世界，只负责把玩家转发到多个子服。

选择核心主要看你要插件、要模组，还是两者都要；同时服务器版本必须和玩家客户端一致。
[/detail]
