# 模组加载器

[brief]
模组加载器是让游戏能加载模组的「中间层」，常见的有 Forge、NeoForge、Fabric、Quilt、OptiFine。装模组前要先装对应的加载器。
[/brief]

[detail]
## 模组加载器是什么

原版 Minecraft 本身不认识[模组](window:/term/mod)。模组加载器（Mod Loader）是一层「中间程序」，让游戏能识别并加载模组。

## 常见的加载器

- **Forge**：最老牌，旧版本模组多，加载较重。
- **NeoForge**：从 Forge 分家，新版本主流。
- **Fabric**：轻量、更新快，新版本常用。
- **Quilt**：Fabric 的社区分支。
- **OptiFine**：偏优化与光影的老方案，与很多模组不兼容。

## 关系图（简化）

```
原版 ——装——> 加载器 ——放模组——> 能玩模组
```

## 注意

- **一个版本一般只装一个主加载器**（Forge / NeoForge / Fabric 三选一）。
- 加载器的版本要和游戏版本对应；加载器要和模组对应（Forge 模组不能丢进 Fabric）。
- 光影加载器（Iris / Oculus / OptiFine）另算，见[光影](window:/term/光影)。
[/detail]
