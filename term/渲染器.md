# 渲染器

[brief]
在这里，渲染器指把游戏的 OpenGL 调用「翻译」给手机 GPU 的程序。选对渲染器，很多画面 / 启动问题就能解决。
[/brief]

[detail]
## 这里的「渲染器」特指什么

在手机 Java 启动器语境里，「渲染器」通常特指**把桌面 OpenGL 转成手机能用的 GLES / Vulkan 的实现**，例如 GL4ES、Krypton Wrapper、Zink、MobileGlues 等。

（广义的渲染器指「把 3D 场景画成画面」的程序，概念更宽，这里不展开。）

## 为什么重要

- 电脑的 OpenGL 手机不一定支持，需要中间层转换。
- 不同渲染器**兼容的版本、性能、光影支持**差别很大。
- 选错渲染器，会出现「进不去世界」「黑屏」「光影全是虚空」等。

## 怎么办

- 不确定就用**默认**渲染器。
- 出问题先换渲染器再排查，详见本站「渲染器选择错误」。
[/detail]
