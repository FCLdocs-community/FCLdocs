# 独立显卡（独显）

[brief]
独立显卡是电脑里专门负责画图的一整块"显卡板卡"，自带显存和芯片，性能比集成在 CPU 里的核显强很多。玩游戏、跑光影主要靠它。
[/brief]

[detail]
## 独显和核显的区别

电脑显示图像有两种方案：

- **核显（集成显卡）**：GPU 集成在 CPU 芯片里，共享系统内存，省电便宜，但性能有限，适合办公、看视频。
- **独显（独立显卡）**：一块单独的板卡，带独立 GPU 芯片和专用显存（VRAM），性能强、发热大、价格高，适合游戏、渲染、AI 计算。

## 为什么游戏需要独显

大型游戏和光影（Shader）需要大量并行图形计算。独显拥有成百上千个流处理器和高速显存，能同时处理海量像素，而核显很快就会被拖垮。

## 主流独显厂商

- **NVIDIA（英伟达）**：GeForce 系列，如 GTX 1650、RTX 3060、RTX 4090，支持光追。
- **AMD（超威）**：Radeon 系列，如 RX 6600、RX 7900 XTX。
- **Intel**：近年推出 Arc 系列独显。

## 和手机的关系

手机没有"独立显卡"这个概念，GPU 集成在 SoC 里。所以手机上跑 Minecraft Java 版光影时，压力比有独显的电脑大得多，这也是手机玩光影吃力、发热大的根本原因。
[/detail]
