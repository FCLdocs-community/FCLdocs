# 环境变量（Environment Variable）

[brief]
环境变量是操作系统传给程序的"键值对配置"，比如库从哪里找（LD_LIBRARY_PATH）、用哪个渲染器（POJAV_RENDERER）。改环境变量常能解决启动或渲染问题。
[/brief]

[detail]
## 它是什么

环境变量是一组 `名称=值` 的设置，程序启动时由系统传入，程序可以读取它来决定行为。

## 常见例子

- `LD_LIBRARY_PATH`：告诉系统去哪里找 `.so` 库；
- `POJAV_RENDERER`：启动器用它选择渲染后端；
- `XDG_DATA_HOME`：某些整合包用来定位数据目录。

## 在 FCL 里怎么用

FCL 的「版本设置 → 环境变量」可以给某个实例单独添加变量，常用来指定 Java 路径、修复渲染器加载、兼容 lwjgl3ify 整合包等。

:::note
变量名区分大小写，格式一般是 `名称=值`，不要多加空格。
:::
[/detail]
