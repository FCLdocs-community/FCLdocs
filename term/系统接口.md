# 系统接口（API 接口）

[brief]
系统接口是系统提供给 App 的"办事窗口"：App 想调用摄像头、定位、文件等系统能力，都得通过这些接口申请。
[/brief]

[detail]
## 系统接口是什么

系统接口（System API / System Interface）是操作系统对外开放的一组编程接口。应用程序通过调用这些接口，才能使用系统的底层能力，比如访问文件、调用相机、获取定位、联网等。

## 作用

- **封装底层**：App 不用直接操作硬件，通过接口即可使用系统功能。
- **权限管控**：系统通过接口检查 App 的权限，未经授权无法调用。
- **隔离与安全**：限制 App 只能做系统允许的事。

## 在手机云控语境中的含义

厂商云控会通过系统预留的接口，实现远程推送、诊断、收集数据等功能。这些接口本是为系统管理服务，但若被滥用，也可能成为过度收集用户数据、控制用户设备的通道。这也是云控引发争议的原因之一。
[/detail]
